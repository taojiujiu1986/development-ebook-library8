## 一、HTML 是什么，能做什么？

HTML 的全称是 **超文本标记语言**。你先不用被名字吓到，在本书里可以把它理解成：**用一套标签，告诉浏览器网页各部分是什么。**

它主要负责这些事：

- 写网页标题
- 写段落文字
- 放图片
- 做链接
- 排列列表
- 组织表格
- 搭出表单
- 用语义标签分清内容

也就是说，HTML 负责的是**内容结构**，不是“好不好看”。  
好看通常是 CSS 的事。赵老师提醒你：**先会搭骨架，再考虑装修。**

比如你想做一个“个人介绍页”，HTML 就能帮你安排：

- 页面标题叫什么
- 头像放在哪里
- 自我介绍写在哪一段
- 兴趣爱好用列表展示
- 联系方式用链接打开

这些都属于 HTML 的工作范围。

## 二、网页、浏览器、HTML 三者是什么关系？

这个问题很重要，很多人第一次学会混。

### 1. HTML 是“材料和图纸”
HTML 文件里写的是网页内容和结构，比如标题、图片、链接。它本身不直接显示，只是把信息写清楚。

### 2. 浏览器是“施工和展示的人”
你写好的 HTML 交给浏览器，浏览器会把代码解释出来，显示成网页。

### 3. 网页是“最终看到的结果”
你在浏览器里打开页面，看到的那个界面，就是网页。

你可以这样记：

> **HTML 负责描述，浏览器负责展示，网页是最终效果。**

### 可直接复制的最小示例代码

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>我的第一个网页</title>
  </head>
  <body>
    <h1>你好，HTML！</h1>
    <p>这是我写的第一个网页。</p>
  </body>
</html>
```

这段代码先不用全懂，后面我们会一块一块拆开。

## 1. HTML 文档的基本结构：DOCTYPE、html、head、body 是什么？

一个标准的 HTML 页面，通常长这样：

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>我的第一个网页</title>
</head>
<body>
    你好，世界！
</body>
</html>
```

先不用背，先看懂它们各自干什么。

### 1.1 `<!DOCTYPE html>`：告诉浏览器“这是 HTML5 页面”

这句放在最顶部，作用是**让浏览器知道你写的是现代 HTML 页面**。  
你可以把它理解成“开场白”。浏览器看到它，就按 HTML5 的规则来解析。

赵老师式提醒：**这句一般别删。** 新手常见错误之一就是漏掉它，然后页面表现怪怪的，还找不到原因。

### 1.2 `<html>`：整个网页的外壳

`html` 标签包住整个页面，意思是：**从这里开始，这就是一个 HTML 文档。**  
它像一个大盒子，里面再分 `head` 和 `body`。

### 1.3 `<head>`：放“看不见但很重要”的内容

`head` 里通常放：

- 网页标题
- 字符编码
- 引入样式文件
- 其他页面配置

简单说，`head` 是给浏览器和搜索引擎看的准备区，不直接显示在页面正文里。

### 1.4 `<body>`：放“真正显示出来”的内容

`body` 里放的是你在页面上能看到的内容，比如标题、段落、图片、链接、列表、表单。  
记住一句话：**写给用户看的内容，放 `body`。**

赵老师式提醒：**别把 `title` 写到 `body` 里，也别把正文塞到 `head` 里。**

---

## 2. head 和 body 分别放什么？别把内容塞错地方

新手第一次写页面，最容易把内容乱放。老赵提醒你：**先分清“说明内容”和“显示内容”。**

### 2.1 `head` 里常放什么

最基础的内容通常是：

```html
<head>
    <meta charset="UTF-8">
    <title>我的第一个网页</title>
</head>
```

这里重点看两项：

- `meta charset="UTF-8"`：告诉浏览器用 UTF-8 编码，中文不容易乱码
- `title`：网页标题

如果不写编码，页面有时会出现中文乱码。

### 2.2 `body` 里常放什么

比如：

```html
<body>
    <h1>你好，我是全栈老赵</h1>
    <p>这是我写的第一个网页。</p>
</body>
```

这两句会直接显示在页面上。  
所以判断标准很简单：

- **要显示在网页上的，放 `body`**
- **不直接显示、但对页面有帮助的，放 `head`**

赵老师式提醒：**位置一错，页面就容易乱。**

---

## 3. `title` 标签的作用：网页标题从哪里来？

你打开网页时，浏览器标签页上那一行字，就是 `title` 标签提供的。

### 3.1 示例

```html
<head>
    <title>我的第一个网页</title>
</head>
```

### 3.2 它有什么用？

`title` 主要有两个作用：

1. 显示在浏览器标签页上
2. 帮用户快速识别网页内容

标题写清楚，用户一眼就知道这个页面是干什么的。

赵老师式提醒：**别小看这个标题。** 以后做网页，标签页上的标题就是用户看到的第一眼信息。

## 4. 如何保存并用浏览器打开第一个 HTML 文件？

代码写完了，下一步是让它跑起来。

### 4.1 保存文件

你可以用记事本、VS Code 或其他编辑器。保存时注意两点：

1. 文件后缀名要是 `.html`
2. 编码尽量选 UTF-8

例如文件名可以叫：

```text

```

如果保存成 `.txt`，浏览器就不一定按 HTML 页面处理。

### 4.2 用浏览器打开

- 双击 `.html` 文件
- 拖进浏览器窗口

### 4.3 如果页面没显示对，先查这几个地方

赵老师给你一个检查清单：

- 文件是不是 `.html` 后缀？
- 代码有没有完整保存？
- `head`、`body` 标签有没有写错？
- 中文是否乱码？看看有没有 `meta charset="UTF-8"`
- 浏览器打开的是不是你刚保存的那个文件？

先从这些地方查，基本不会跑偏。

## 6. 赵老师式提醒：代码写错别怕，先学会看浏览器反馈

新手学 HTML，最重要的不是一次写对，而是**知道错了怎么找**。  
浏览器其实很诚实：

- 少了标签，结构可能不完整
- 标签写错，内容可能不显示

### 6.1 常见小错误

比如：

```html
<head>

    <p>少了闭合标签

```

这里的问题有：

- `head` 没有正确结束

- 结构不完整

### 6.2 面对错误的正确姿势

记住这个顺序：

1. 看页面有没有显示
2. 看标题有没有出来
3. 检查标签是否成对
4. 检查文件名和编码

赵老师式提醒：**前期别追求写得多，先追求看得懂、跑得通。** 能把第一个页面打开，你就已经迈出第一步了。

## 一、标题标签 `h1` 到 `h6`：怎么给内容分层？

标题标签有 6 个等级，从 `h1` 到 `h6`，数字越小，标题越重要、越大。你可以把它理解成“从大标题到小标题”的层级。

### 1. 使用场景怎么选？

- `h1`：页面主标题，通常一个页面放 1 个
- `h2`：一级小标题
- `h3`：`h2` 的下一级标题
- `h4`、`h5`、`h6`：更细的层级，按需使用

你可以把它理解成写文章：先有文章题目，再有“第一部分”“第二部分”，再往下分小点。

### 2. 记住一个原则

标题不是为了“看起来大一点”，而是为了让内容有顺序。  
比如个人介绍页里：

- `h1` 放“我的个人主页”
- `h2` 放“我是谁”“我喜欢什么”“我的学习计划”

这样一看，读者马上知道哪部分最重要，浏览器也更容易理解页面结构。

### 3. 示例代码

```html
<h1>全栈老赵的自我介绍</h1>
<h2>我是谁</h2>
<h3>我的兴趣</h3>
<h3>我正在学习什么</h3>
<h2>我的计划</h2>
<h3>短期目标</h3>
<h3>长期目标</h3>
```

### 4. 常见误区

- 把 `h1` 当成只是“加粗变大”
- 一个页面到处乱用 `h1`
- 标题层级跳着用，比如直接从 `h1` 跳到 `h4`

**赵老师式提醒：**  
标题是“结构”，不是“装饰”。先想清楚内容层次，再选标签。

### 小练习

给你的个人介绍页写 1 个 `h1` 和 3 个 `h2`，主题可以是：  
“我是谁”“我喜欢什么”“我想学什么”。

## 二、段落标签 `p`：正文应该怎么写？

如果说标题是“路牌”，那段落就是“正文内容”。  
`p` 标签用来放一整段话，适合描述、介绍、说明等内容。

### 1. 正确用法

一段完整的文字，用一个 `p` 包起来。  
不要把很多段话硬塞进一个 `p` 里，也不要把每一行都单独写成一个 `p`。

你可以这样理解：一段话讲一个意思，换一个意思，就另起一个段落。

### 2. 示例代码

```html
<p>大家好，我是全栈老赵。欢迎来到我的 HTML 入门页面。</p>
<p>我正在学习前端基础，希望先把网页骨架搭好，再慢慢学会排版和美化。</p>
```

### 3. 需要记住的规则

- `p` 是“段落”，不是“单行文字”
- 段落之间浏览器会自动留出空白
- 不要为了“看起来分行”而滥用 `br`

## 三、换行 `br` 与空格：浏览器到底怎么显示？

很多新手第一次写 HTML 时都会疑惑：  
“为什么我敲了很多空格，网页上只显示一个？”  
“为什么我换了好多行，页面还是挤在一起？”

这就要明白浏览器显示文字的基本规则。

### 1. `br` 是什么？

`br` 表示**强制换行**，常用于地址、诗句、联系信息这类确实需要断开的地方。  
它只是换行，不是换段落。

### 2. 示例代码

```html
<p>
  联系方式：<br>
  微信：xxxxxx<br>
  邮箱：test@example.com
</p>
```

### 3. 空格为什么不明显？

浏览器会把连续空格自动合并成一个空格。  
所以 HTML 不适合靠空格摆版面，想控制结构，应该优先用标题、段落、列表这些标签。

### 4. 常见误区

- 用很多 `br` 来代替段落
- 想靠空格把页面“排整齐”
- 误以为输入几行，页面就会显示几行

**赵老师式提醒：**  
要换段落，用 `p`；要强制断行，才用 `br`。别乱堆，不然代码会很难维护。

### 小练习

写一段联系方式内容，要求：  
- 使用 1 个 `p`
- 里面至少有 2 处 `br`

## 四、注释 `<!-- -->`：为什么要给自己留说明？

注释是写给“未来的自己”和“看代码的人”看的。  
它不会显示在网页上，但会保留在 HTML 文件里，帮助你记录想法、临时说明、待办事项。

### 1. 注释怎么写？

```html
<!-- 这是一个注释 -->
```

### 2. 注释的作用

- 说明某一段代码是做什么的
- 临时隐藏内容，不删除代码
- 给自己留提醒，比如“这里后面要加图片”

你刚开始学 HTML，代码会越来越长。  
这时候有注释，就像给自己的笔记做小标签，回头一看就知道哪块是标题，哪块是介绍，哪块还没写完。

### 3. 示例代码

```html
<!-- 页面主标题 -->
<h1>我的个人主页</h1>

<!-- 下面是简介部分 -->
<p>我是一个刚开始学习 HTML 的新手。</p>

<!-- TODO：后面补充头像图片 -->
```

### 4. 常见误区

- 把注释写成页面内容的一部分
- 注释太长太乱，自己都看不懂
- 以为注释也会显示在网页上

**赵老师式提醒：**  
注释不是装饰，是“给代码做笔记”。别嫌麻烦，后面调试时能省很多时间。

### 小练习

在你的页面代码里加 3 条注释：  
1 条说明标题部分，1 条说明正文部分，1 条写待办事项。

## 六、赵老师式提醒：别把所有文字都塞进一个标签里

```html
<h1>我是小李</h1>

<p>我正在学习 HTML。</p>
<p>我以后想做一个网站。</p>
```

这样内容清楚，结构也清楚。  
**记住一句话：先分层，再写内容。**

# 第4章：给网页加一点结构感——`div`、`span` 和常见属性

## 开篇引入：本章只学三件事

前面我们已经会写 HTML 的基本骨架、标题、段落、链接和图片了。这一章不讲布局，也不讲美化，先只学三件事：

1. `div` 是什么：常见的块级容器  
2. `span` 是什么：常见的行内容器  
3. 常见属性怎么写：`class`、`id`、`style`、`title`

你可以把这一章理解成：先学会“把内容包起来”，让网页更有条理。赵老师先提醒你一句：**先学会“包起来”，再谈美化。** 这一步很基础，但特别重要。

## 1. `div` 是什么：常见的块级容器

### 1.1 `div` 的作用

`div` 可以理解成一个**大盒子**。它本身不表示具体内容，只负责把一整块内容装起来，方便分区和整理。

你只要先记住一句话：

- 想包一整块内容，用 `div`

### 1.2 `div` 的特点

`div` 通常会：

- 独占一行
- 适合包住一组内容
- 方便以后统一处理

比如一个简单的个人介绍页，可以分成“自我介绍”和“兴趣爱好”两块，这两块就很适合分别用 `div` 包起来。

### 1.3 可直接复制的示例代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的个人介绍页</title>
</head>
<body>
  <div>
    <h1>老赵</h1>
    <p>我正在学习 HTML，准备一步一步做出自己的网页。</p>
  </div>

  <div>
    <h2>我的爱好</h2>
    <p>喜欢阅读、散步和写代码。</p>
  </div>
</body>
</html>
```

### 1.4 赵老师式提醒

`div` 就像大箱子，适合装“一整组内容”。先分块，再考虑其他事情，网页结构才会清楚。

---

## 2. `span` 是什么：常见的行内容器

### 2.1 `span` 的作用

如果说 `div` 是大盒子，那 `span` 就像句子里的小标签。它通常用来包住一小段文字，方便单独标出来。

你可以把它记成一句话：

- 想包一句话里的小部分，用 `span`

### 2.2 `span` 的特点

`span` 一般用于行内内容，特点是：

- 不会把内容拆成大块
- 适合包住一句话中的某个词
- 常用于强调重点文字

```html
<p>我正在学习 <span>HTML</span>，今天重点认识 div 和 span。</p>
```

这里 `span` 只是把 `HTML` 这一小段包起来，后面要单独处理会很方便。

### 2.3 可直接复制的示例代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>span 示例</title>
</head>
<body>
  <p>我正在学习 <span>HTML</span>，今天重点认识 div 和 span。</p>
</body>
</html>
```

### 2.4 赵老师式提醒

`span` 适合“点一下、强调一下”，不要拿它去包一大段内容。你只要先记住：

- 一整块内容，用 `div`
- 一小段文字，用 `span`

### 2.5 小练习

写一个段落，把你最喜欢的一个词用 `span` 包起来，比如“前端”“学习”“代码”“音乐”。

## 3. 常见属性：给标签补充一点信息

### 3.1 属性是什么？

属性是写在标签里的附加信息，用来告诉浏览器，这个标签还有哪些额外特点。

基本写法是：

```html
标签名 属性名="属性值"
```

比如：

```html
<p class="intro">这是介绍文字。</p>
```

这里的 `class="intro"` 就是属性。

### 3.2 `class`：给一类内容起名字

`class` 可以理解成“分类名”。如果有很多相似内容，想统一管理，就可以用它。

```html
<p class="tip">这是提示信息。</p>
<p class="tip">这是另一条提示信息。</p>
```

这两个段落都属于同一类，后面想统一处理就很方便。

### 3.3 `id`：给一个内容单独编号

`id` 更像“唯一身份证”，通常用来标识页面里某一个特别的元素。

```html
<h1 id="main-title">我的主页</h1>
```

新手先记住这两个区别就行：

- `class`：一类一类地管
- `id`：一个一个地找

### 3.4 `style`：直接写一点样式

`style` 可以直接在标签里写样式，比如：

```html
<p style="color: red;">这段字是红色的。</p>
```

这一章你先知道它是“临时加样式”的方式就行，重点还是先把结构写清楚。

### 3.5 `title`：鼠标移上去时显示提示

`title` 很适合做说明。写上以后，鼠标移到元素上，会看到提示文字。

```html
<p title="这是一个提示">把鼠标移上来看看。</p>
```

它常用于备注、小提醒、补充说明。

### 3.6 可直接复制的示例代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>属性示例</title>
</head>
<body>
  <h1 id="main-title">我的个人页面</h1>

  <p class="intro" title="这是自我介绍">
    我正在学习 HTML，慢慢搭建自己的网页。
  </p>

  <p style="color: blue;">这是一段蓝色文字。</p>
</body>
</html>
```

### 3.7 小练习

请你给下面内容加上属性：

- 一个 `h1`，加上 `id`
- 一个介绍段落，给它加上 `class`
- 再写一个 `p`，加上 `title`

如果你能一眼看出“哪个是标题、哪个是介绍、哪个是提示”，就说明你已经开始会用属性整理页面了。

## 一、先认识列表：把内容一条条摆好

网页里经常要放一串内容，比如爱好、步骤、菜单、待办事项，这时候就适合用列表。HTML 里最常用两种：

- **无序列表 `ul`**：强调并列关系，不强调顺序
- **有序列表 `ol`**：强调先后顺序，适合步骤、流程、排名

列表里的每一项都要写在 **`li`** 标签里。

### 1. 无序列表：适合并列信息

```html
<ul>
  <li>阅读</li>
  <li>写代码</li>
  <li>听音乐</li>
</ul>
```

这种内容谁先谁后不重要，放在一起就行，所以用 `ul` 很合适。

### 2. 有序列表：适合步骤顺序

```html
<ol>
  <li>打开编辑器</li>
  <li>新建 HTML 文件</li>
  <li>保存并在浏览器中打开</li>
</ol>
```

这个例子里顺序不能乱，所以适合用 `ol`。

### 3. 什么时候选哪一个？

- 只是“列出来”，用 `ul`
- 要“按顺序做”，用 `ol`

赵老师式提醒：**别把列表写成一堆 `<p>`，那样结构会乱，后面也不好改。**

### 4. 小练习

写一个“我的周末安排”：

- 用无序列表写 3 个兴趣爱好
- 用有序列表写 3 步学习流程

检查一下：**每一项是不是都放进了 `li`？并列内容和步骤内容有没有分开？**

## 二、超链接：让页面能跳到别的地方

网页能互相连接，靠的就是 **超链接 `a` 标签**。链接的作用就是“去别的地方看看”，可以是外部网站、自己网站里的另一页，也可以是当前页面的某个位置。

### 1. 基本写法

```html
<a href="https://www.example.com">访问示例网站</a>
```

这里最关键的是：

- `a`：表示链接
- `href`：表示跳转地址

### 2. 链接不只指向外部网站

```html
<a href="about.html">进入“关于我”页面</a>
```

链接可以指向：

- 外部网站
- 你自己的其他网页
- 页面内部某个位置

### 3. 外部链接、站内链接、锚点链接

- **外部链接**：跳到别的网站，常用于参考资料
- **站内页面链接**：跳到自己网站的其他页面，常用于“关于我”“联系我”
- **页面锚点链接**：跳到当前页面的某一段，常用于“返回顶部”

```html
<a href="https://www.baidu.com">搜索一下</a>
<a href="about.html">关于我</a>
<a href="#top">返回顶部</a>
```

### 4. 链接还可以跳到页面内部

先给目标位置起一个名字：

```html
<h2 id="top">页面顶部</h2>
```

再写链接：

```html
<a href="#top">返回顶部</a>
```

这里的 `#top` 就是跳到 `id="top"` 的位置。

赵老师式提醒：**同页跳转不是魔法，本质就是“找到一个带 id 的位置，再跳过去”。**

### 5. 常见误区

1. 忘记写 `href`，链接就没法跳转  
2. 地址写错，点了没反应  
3. 把 `a` 当按钮用，链接和按钮功能别混

赵老师式提醒：**先想清楚自己要“跳转”，还是要“操作”，再决定用什么标签。**

### 小练习

写 3 个链接：

- 一个跳到百度或其他网站
- 一个跳到你自己的 `about.html`
- 一个跳到 `contact.html`

检查标准：**文字能不能点？地址是不是写在 `href` 里？页面内跳转有没有 `#`？**

## 三、图片：让页面更直观

图片能让页面更直观，HTML 里插入图片用 **`img` 标签**。

### 1. 基本写法

```html
<img src="cat.jpg" alt="一只可爱的猫">
```

记住两个属性：

- `src`：图片地址
- `alt`：图片说明

`src` 决定图片从哪里来，`alt` 决定图片没显示出来时怎么办。

### 2. `alt` 为什么重要？

`alt` 很实用：

- 图片加载失败时，会显示替代文字
- 读屏工具可以读出图片内容
- 方便你以后回头看懂这张图是做什么的

赵老师提醒：**新手最容易只写 `src` 不写 `alt`，这不是好习惯。**

例如：

```html
<img src="images/avatar.png" alt="我的头像">
```

### 3. 图片路径先写清楚，再复制

图片经常不显示，很多时候不是标签错，而是路径写错了。  
先记住一个常见项目结构：

```text
my-page/
├─ index.html
├─ about.html
├─ contact.html
└─ images/
   └─ avatar.png
```

如果 HTML 文件和图片在同一层，路径可以直接写文件名；如果图片在文件夹里，就要把文件夹名写进去。

比如图片真实名字是：

```text
avatar.png
```

那就写成：

```html
<img src="images/avatar.png" alt="我的头像">
```

注意这些都要对上：

- 文件名是不是 `avatar`
- 后缀是不是 `.png`
- 大小写是不是一致
- 图片是不是确实放在 `images` 文件夹里

赵老师式提醒：**图片不显示时，先看路径，再看文件名，再看图片是否真的存在。**

### 4. `src`、`alt`、`title` 的区别

- `src`：图片文件在哪儿
- `alt`：图片没显示出来时的说明
- `title`：鼠标放上去时的额外提示

```html
<img src="images/avatar.png" alt="我的头像" title="这是我的头像">
```

赵老师式提醒：**`alt` 是说明，不是装饰；`title` 是补充提示，不是必须。**

### 5. 小练习

插入一张图片，并写上说明文字：

- `src` 指向一张你电脑里的图片
- `alt` 写成“我的头像”或“我的风景照”

检查一下：**有没有写 `alt`？图片路径是不是写对了？图片文件是不是真的存在？**

## 四、相对路径与绝对路径：先会用，再慢慢理解

图片不显示、链接点不开，很多时候都是**路径写错了**。这一节你先不用怕，先记住“怎么用”，以后再慢慢理解原理。

### 1. 什么是相对路径？

相对路径就是：**从当前文件出发，去找目标文件**。它最适合项目内部互相引用。

```html
<img src="images/pic.jpg" alt="图片">
<a href="about.html">关于我</a>
```

意思是：

- 图片在 `images` 文件夹里
- `about.html` 和当前页面在同一层级

### 2. 什么是绝对路径？

绝对路径就是：**写完整地址**。

```html
<a href="https://www.example.com">示例网站</a>
```

这就是绝对路径的一种写法，地址完整，不依赖当前文件在哪。

新手先记住：**自己项目里的文件，多半优先想相对路径。**

### 3. 相对路径和绝对路径怎么选？

| 类型 | 适合场景 | 优点 | 注意点 |
|---|---|---|---|
| 相对路径 | 自己项目内部文件 | 简单、灵活 | 要和文件位置对应 |
| 绝对路径 | 外部网站、完整地址 | 一眼看懂 | 长、依赖完整 URL |

赵老师式提醒：**自己项目里的文件，用相对路径；去外部网站，用绝对路径。**

### 4. 小练习

假设你的项目结构是：

```text
index.html
images/avatar.png
about.html
```

请分别写出：

- `index.html` 中引用头像图片的路径
- 跳转到 `about.html` 的链接写法

检查标准：**有没有把链接地址和图片地址分清楚？路径和文件位置有没有对应上？**

## 五、把列表、链接、图片放在一起：最实用的综合示例

下面这个例子可以直接复制。它把**列表、链接、图片**放在一起，适合做一个简单的个人介绍页。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>我的个人介绍</title>
</head>
<body>
  <h1 id="top">你好，我是小赵</h1>

  <p>我正在学习 HTML，这是我的第一个网页。</p>

  <ul>
    <li>看书</li>
    <li>写代码</li>
    <li>跑步</li>
  </ul>

  <h2>我的照片</h2>

  <h2>常用链接</h2>
  <p>
    <a href="about.html">关于我</a>
    |
    <a href="https://www.baidu.com">搜索一下</a>
    |
    <a href="contact.html">联系我</a>
  </p>

  <p>
    <a href="#top">返回顶部</a>
  </p>
</body>
</html>
```

### 这个例子你要看懂什么？

- 标题用 `h1`、`h2`
- 段落用 `p`
- 爱好用无序列表 `ul`
- 图片用 `img`
- 页面跳转用 `a`

这就是一个典型的简单信息页。你先别追求复杂样式，先把内容摆整齐。

赵老师式提醒：**链接写出来不难，关键是“目标位置”也要准备好。别光写跳转，不写落点。**

### 小练习

- 把爱好改成你的真实兴趣
- 把图片换成你自己的头像
- 把链接改成你想展示的页面
- 给页面顶部加上 `id="top"`，让“返回顶部”真正生效

检查标准：**页面里有没有标题、段落、列表、图片、链接这五样东西？内容是不是清楚好读？**

## 六、补充认识：div 和 span 是什么？

学到这里，你已经会把内容放进页面了。再认识两个很常见的“容器标签”：

- **`div`**：块级容器，常用来装一大块内容
- **`span`**：行内容器，常用来包住一小段文字

你现在不用想得太复杂，先理解成“装东西的盒子”就行。

### 1. `div`：装一整块内容

```html
<div>
  <h2>个人简介</h2>
  <p>我喜欢学习前端，也喜欢记录生活。</p>
</div>
```

### 2. `span`：装一句话里的某个小部分

```html
<p>我最喜欢的颜色是 <span>蓝色</span>。</p>
```

`span` 自己不会换行，适合包住文字中的一小段。

赵老师式提醒：**先别急着用它们做复杂布局。你现在只要记住：`div` 装大块，`span` 装小段。**

# 第6章：让网页更像一页“内容页”——段落组合与信息排版

这一章是一个过渡练习章。我们不追求复杂效果，主要练一件事：**把标题、段落、图片、链接组合成一块完整内容**，让网页从“零散标签”变成“像样的一页内容”。

赵老师先提醒你一句：**网页不是把东西一股脑丢进去，而是要有顺序、有层次地摆进去。**

## 一、这一章只学什么？

本章只练一个核心思路：**先分区，再填内容。**

你可以把它理解成做一块“信息卡片”：

- 先定这块内容讲什么
- 再把相关文字放进去
- 再补一张图片
- 再加一个链接
- 最后用 `div` 把它们包起来

这样写出来的页面，虽然还不复杂，但已经比“标签散装堆放”清楚多了。对于零基础来说，这一步很重要，因为后面做个人介绍页、简单信息页，基本都是这个套路。

## 二、把零散内容放成一块：先分区，再填内容

很多新手写网页时，最常见的问题不是不会写标签，而是**一上来就把所有内容塞进 `body` 里**。结果就是：有标题、有图片、有文字，但看起来像一堆零件。

正确做法很简单：

1. 先想清楚这一块内容的主题
2. 再把相关内容放进同一个区域
3. 不相关的内容，分到别的区域去

这里最常用的就是 `div`。你可以把 `div` 理解成一个“盒子”，它本身不代表具体内容，但很适合把一组相关内容装在一起。

```html
<div>
  <h2>关于我</h2>
  <p>我喜欢学习前端，也喜欢记录自己的学习过程。</p>
</div>
```

这段代码表示：标题和段落是一组内容，所以放进同一个盒子里。

赵老师式提醒：**先分区，再填内容。不要一边写一边乱跳。**

## 三、这一页里最常见的组合方式

一个简单的内容页，通常就是把这些东西配在一起：

- 一个标题，说明这页讲什么
- 一两段文字，补充介绍
- 一张图片，增加直观感
- 一个链接，方便继续了解

下面先看一个最简单的组合示例。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的个人介绍</title>
</head>
<body>
  <h1>你好，我是赵小明</h1>
  <p>我正在学习 HTML，希望做出自己的第一个网页。</p>
  <img src="avatar.jpg" alt="我的头像" width="160">
  <p>
    欢迎访问我的
    <a href="https://example.com" target="_blank">个人主页</a>
  </p>
</body>
</html>
```

这段代码里：

- `h1` 负责说主题
- `p` 负责讲内容
- `img` 负责补视觉
- `a` 负责跳转

你不用急着记很多规则，先记住一个感觉：**内容之间要有顺序，不能像抽屉里乱塞东西。**

## 四、常见属性怎么用，才算真的在组织内容？

这一章我们不讲复杂语法，只看几个最常用、最实用的属性。

### 1. `alt`：给图片一个替代说明

```html
<img src="photo.jpg" alt="我在公园拍的照片">
```

`alt` 的作用很实际：图片加载失败时能显示说明；有些辅助工具也会读它。  
新手很容易忘记写，但它其实很重要。

### 2. `href`：给链接指定地址

```html
<a href="https://www.baidu.com">去百度</a>
```

没有 `href`，链接就只是普通文字，不会真的跳转。  
赵老师提醒你：**写链接先看地址，再看文字。**

### 3. `title`：鼠标移上去时的提示

```html
<p title="这是我的兴趣介绍">我喜欢编程和阅读。</p>
```

这个属性不是必须的，但有时候能给读者一点补充提示。

### 4. `id` 和 `class`：给内容做标记

```html
<div id="profile" class="card info-box">
  <p>这里是一块个人信息区域。</p>
</div>
```

你现在不用深入样式，只要先记住：

- `id` 像身份证号，通常一个页面里尽量唯一
- `class` 像标签名，可以重复使用

赵老师提醒：**属性不是装饰品，它们是在帮你给网页内容贴标签。**

## 五、可直接复制的个人信息卡片

下面这段你可以直接复制到 HTML 文件里练习。它把标题、段落、图片、链接、`div`、属性、注释都放进去了，很适合当作第一块“像样的内容页”模板。

```html

</head>

  <h1>你好，我是赵小明</h1>

```

这段代码里你要重点记住四件事：

- `head` 里放页面信息，不放正文
- `body` 里放真正显示的内容
- `div` 负责分区
- `<!-- 注释 -->` 是给自己看的，不会显示在页面上

这里的图片路径写成 `images/me.jpg`，表示图片放在当前 HTML 文件旁边的 `images` 文件夹里。

## 开篇引入：什么时候该用表格？

前面我们已经认识了标题、段落、图片、链接这些网页里的基本零件。这一章，我们来聊一个很实用、也很容易被新手误会的东西：**表格**。

你可以把表格理解成“把信息按行和列摆整齐”。它最擅长的不是“好看”，而是“清楚”。比如：

- 课程表
- 价格对比
- 商品清单
- 成绩统计
- 人员信息列表

这些内容的共同点是：**需要一眼看出对应关系**。谁是什么、多少、在哪一列，一看就明白，这时候表格就很合适。

**赵老师式提醒：**  
表格的任务是“展示结构化信息”，不是拿来随便排版的。很多新手一看到“要整齐”，就想用表格拼整个页面，这个思路要尽早改掉。**标签要用对地方，页面才会越做越顺。**

---

## 一、`table`、`tr`、`th`、`td` 是什么关系？

表格的骨架很简单，先把这四个标签认熟就够了：

- `table`：表格整体
- `tr`：一行
- `th`：表头单元格
- `td`：普通单元格

你可以理解成：

- `table` 是整张表
- `tr` 是一排
- `th/td` 是这一排里的格子

### 1）最基础的结构

```html
<table>
  <tr>
    <th>姓名</th>
    <th>年龄</th>
  </tr>
  <tr>
    <td>小明</td>
    <td>18</td>
  </tr>
  <tr>
    <td>小红</td>
    <td>20</td>
  </tr>
</table>
```

这段代码的意思很直接：

- 第一行是表头：姓名、年龄
- 后面每一行是具体数据

你先别急着背，先学会看结构。记住一句话就够了：

> 一张表 = `table` 包住很多 `tr`，每个 `tr` 里放 `th` 或 `td`

**小提醒：**  
`th` 一般表示表头，它的作用不只是“更显眼”，更重要的是告诉读者：这一列讲的是什么。

### 小练习

自己写一个“三行两列”的表格，内容可以是：

- 姓名 / 职业
- 书名 / 作者
- 城市 / 备注

先把结构写对，比一开始写得花哨更重要。

## 二、表格适合展示什么？不适合展示什么？

### 1）适合展示的内容

表格最适合这些信息：

- **对比类**：价格、参数、优缺点
- **清单类**：课程列表、商品列表
- **规则类**：时间安排、成绩记录
- **对应关系**：姓名—电话、城市—邮编

它们的共同点是：**行列关系明确**，放进表格里最容易看懂。

### 2）不适合展示的内容

表格不适合：

- 随便拿来拼页面
- 做首页大布局
- 堆很多图片和按钮
- 负责复杂视觉效果

如果你只是想让几个模块左右排列，别优先想到表格。那样代码难读，后面也不好改。

**赵老师式提醒：**  
表格像“信息收纳盒”，不是“万能积木”。它适合装规整信息，不适合硬凑页面样式。

### 3）一个简单判断标准

你可以问自己一句：

> 这组内容是不是“按行按列看最清楚”？

如果是，优先考虑表格；如果不是，就先别急着用表格。

## 三、表格标题和表头怎么写？

### 1）表头的作用

表头就是告诉别人“这一列是什么”。例如：

```html
<table>
  <tr>
    <th>姓名</th>
    <th>分数</th>
  </tr>
</table>
```

有了表头，读者一眼就知道下面的数据在说什么。没有表头，表格就容易变成一堆整齐但不好懂的内容。

### 2）表格标题怎么做？

在本书当前阶段，先掌握最容易理解的写法：**把标题写在表格上方的段落里**。

```html
<p>班级成绩表</p>
<table>
  <tr>
    <th>姓名</th>
    <th>分数</th>
  </tr>
  <tr>
    <td>小明</td>
    <td>95</td>
  </tr>
</table>
```

这样虽然简单，但很适合零基础入门。先把“能表达清楚”放在第一位，后面再慢慢细化。

### 3）标题和表头别混了

- **标题**：整张表在讲什么
- **表头**：每一列表示什么

比如“班级成绩表”是标题，“姓名”“分数”是表头。一个管整体，一个管局部，别弄混。

### 小练习

给下面这张表补一个合适的标题和表头：

- 第1列：商品名
- 第2列：价格
- 第3列：库存

你可以先自己想一版，再写成 HTML。

## 五、把表格放进实际页面时，要注意什么？

### 1）表格前最好有说明

表格不是孤零零放上去就完事了。通常先给一句说明，读者会更容易明白。

```html
<p>以下是本周课程安排：</p>
```

这样读者在看表格之前就知道它在讲什么。

### 2）内容要简洁清楚

表格里的字不要太长，不然一格里塞太多内容，阅读体验会变差。记住一句话：

> 表格中的内容，越规整越好。

如果某个格子里写了一大段话，那它可能就不太适合放在表格里了。

### 3）不要把所有信息都塞进表格

如果一段内容更适合用段落、列表、图片展示，就别硬塞进表格。

比如：

- 自我介绍：更适合段落
- 兴趣爱好：可以用列表
- 联系方式对照：可以用表格

这就是“选对工具”。会用标签，不只是会写，还要知道什么时候用。

### 4）表格和其他标签一起用

实际页面中，表格往往和标题、段落、列表一起出现。它们是配合着工作的：

- 标题告诉别人“这是什么”
- 段落说清背景
- 表格把数据摆整齐

配合起来，页面就会很清楚。

## 六、赵老师式提醒：表格是展示结构化信息，不是万能排版工具

这部分一定要记住。

很多新手学 HTML 时，会觉得“只要页面能摆整齐，什么都可以用表格”。其实不对。

表格有自己的职责：

- 展示行列清晰的数据
- 让读者快速对比信息
- 让规则、清单、数据更容易读

它不负责：

- 页面美化的全部工作
- 复杂布局的通用方案
- 替代标题、段落、列表等语义标签

**赵老师式提醒：**  
你现在是在学“把信息讲清楚”，不是在追求“先把页面摆出来再说”。先用对标签，再谈好看。学 HTML 最怕的不是写慢，而是方向一开始就错。

## 开篇引入：网页不只是“看”，还可以“填”

前面我们学的网页，多半是在展示内容：标题、段落、图片、链接。到了这一章，网页开始能接收用户输入了。你注册账号、登录网站、搜索内容、留言反馈，背后几乎都离不开**表单**。

赵老师先提醒你一句：**表单先学会“能用”，再考虑“好看”**。新手阶段别急着研究花哨样式，先把最基础的输入框、标签、按钮写对，这一步最重要。

## 1. 表单是什么：让用户填写和提交信息

表单最核心的作用就是**收集信息**。比如登录页、注册页、搜索框、报名页、留言页，都会用到表单。

在 HTML 里，表单通常用 `<form>` 包起来。你可以把它理解成一个“收纳袋”：里面放各种输入控件，最后统一提交给网站。

先记住最基础的一点：**form 负责装内容，提交按钮负责把内容送出去**。至于内容送到哪里、后端怎么处理，这一章先不用深挖。**先会写基础结构，知道它能提交就够了。**

### 可直接复制的基础认识代码

```html
<form>
  <p>用户名：<input type="text"></p>
  <p>密码：<input type="password"></p>
  <button type="submit">提交</button>
</form>
```

这段代码已经有了表单最基本的样子：输入、提交。  
赵老师式提醒：**先看懂它能干什么，比死记标签名更重要。**

### 小练习

2. 再加一个“手机号”输入框。
3. 试着把按钮文字改成“注册”。

## 2. form、input、label、button：先把最基本的骨架认清楚

记住一句话：**form 负责包起来，input 负责输入，label 负责说明，button 负责提交**。

### 2.1 `form`：表单容器

`<form>` 是表单外壳，里面放输入框和按钮。

```html
<form>
  <!-- 表单内容写在这里 -->
</form>
```

### 2.2 `input`：输入框

`<input>` 是最常见的表单元素，配合 `type` 属性可以变成不同输入框。这一章你先认识它，不用一下子背完。

### 2.3 `label`：提示文字

`<label>` 用来告诉用户“这个输入框是干什么的”。别小看它，新手很容易只写输入框不写说明，页面就会显得很乱。

### 2.4 `button`：按钮

`<button>` 用来触发操作，最常见就是“提交”。

### 可直接复制的标准写法

```html
<form>
  <label for="username">用户名：</label>
  <input type="text" id="username" name="username" placeholder="请输入用户名">

  <label for="pwd">密码：</label>
  <input type="password" id="pwd" name="password" placeholder="请输入密码">

  <button type="submit">提交</button>
</form>
```

这里的 `for` 和 `id` 是配对关系。先不用死磕原理，只要先记住：**label 和 input 绑在一起，用户更容易看懂，也更容易点选。**  
赵老师式提醒：**表单不是把控件堆上去就行，清清楚楚告诉别人“这是什么”才是关键。**

### 小练习
1. 把“用户名”和“密码”改成你自己的内容。
2. 把按钮文字改成“登录”。
3. 试着把 `name` 也一起改掉。

## 3. 一个完整表单里，常见输入怎么放在一起？

很多新手会把表单拆得太碎。其实更适合零基础的方法是：**先看一个完整表单，再认识里面每个控件**。

下面这个示例把最常用的几种输入集中到一起，你会更容易形成整体概念。

### 可直接复制的完整表单示例

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>简单信息收集表</title>
</head>
<body>
  <h1>简单信息收集表</h1>

  <form>
    <p>
      <label for="nickname">昵称：</label>
      <input type="text" id="nickname" name="nickname" placeholder="请输入昵称">
    </p>

    <p>
      <label for="password">密码：</label>
      <input type="password" id="password" name="password" placeholder="请输入密码">
    </p>

    <p>性别：</p>
    <label><input type="radio" name="gender" value="男"> 男</label>
    <label><input type="radio" name="gender" value="女"> 女</label>

    <p>兴趣爱好：</p>
    <label><input type="checkbox" name="hobby" value="读书"> 读书</label>
    <label><input type="checkbox" name="hobby" value="运动"> 运动</label>
    <label><input type="checkbox" name="hobby" value="音乐"> 音乐</label>

    <p>
      <button type="submit">提交信息</button>
    </p>
  </form>
</body>
</html>
```

这个例子里，文本框、密码框、单选框、复选框都放在一个表单里了。你只要先记住它们各自适合什么场景：

- **文本框**：填普通文字
- **密码框**：填密码
- **单选框**：只能选一个
- **复选框**：可以选多个

赵老师式提醒：**单选就是“选一个”，复选就是“可多个”**。比如性别通常单选，爱好通常复选，这样记最省脑子。

### 小练习

2. 给表单再加一个“邮箱”输入框。
3. 把按钮改成“保存资料”。

## 4. `placeholder`、`name`、`value`：先记住最实用的几个属性

表单要想“好用”，属性很关键。你现在不需要理解太深，先知道它们各自干什么。

### 4.1 `placeholder`：占位提示

它会在输入框里显示提示文字，告诉用户该填什么。

```html
<input type="text" placeholder="请输入你的名字">
```

### 4.2 `name`：字段名

`name` 相当于给输入内容起名字。表单提交时，浏览器会按 `name` 来组织数据。  
你先记住一句话：**想让这个值被“认识”，就别忘了写 `name`。**

```html
<input type="text" name="username">
```

### 4.3 `value`：默认值或选项值

`value` 可以理解成“这个选项代表什么”。

```html
<input type="radio" name="gender" value="男">
<input type="radio" name="gender" value="女">
```

### 常见小坑

- 只写输入框，不写提示，用户不知道填什么
- 单选框忘了写相同的 `name`
- 单选和复选混用，逻辑不对
- 只看样子，不理解 `name` 和 `value` 的作用

赵老师式提醒：**属性不是装饰，它们往往决定表单能不能正常工作。**

### 小练习
1. 给两个输入框分别加上 `placeholder`。
2. 给单选框和复选框都补上 `value`。
3. 观察这些属性分别有什么作用。

## 6. 赵老师式提醒：表单先能用，再谈好看

很多新手一上来就想把表单做得很炫，结果把重点弄丢了。赵老师建议你按这个顺序来学：

1. **先会写结构**：`form` 里放什么

## 开篇：为什么你已经会写 `div`，还要学语义化？

前面你已经会搭网页了，标题、段落、图片、链接、列表、表格、表单都能写。  
但赵老师提醒你一句：**能显示出来，不等于写得像网页。**

很多新手喜欢这样写：

```html
<div class="top"></div>
<div class="menu"></div>
<div class="content"></div>
<div class="bottom"></div>
```

它能用，但别人一看，不知道每块到底是什么；以后自己回来看，也容易忘。  
语义化标签，就是来解决这个问题的。

它的作用可以直接记成一句话：**让结构更清楚，代码更好懂。**

你可以把它理解成：

- `div` 像普通盒子
- 语义化标签像贴了名字的盒子

## 一、先记住语义化的判断方法

写一个区域前，先问自己：

1. 这块内容是头部、主体、底部吗？
2. 这块内容是导航吗？
3. 这块内容是独立的一块内容吗？
4. 这块内容是补充信息吗？

如果答案很明确，就优先用语义化标签；如果只是普通分组，没有特殊含义，再用 `div`。

## 二、这几个最常见的语义化标签，先会用就行

这一节只讲最常用的，够你入门使用了。

### 1. `header`：页面或区域的头部

常放网站标题、Logo、顶部导航等。

```html
<header>
  <h1>全栈老赵的学习笔记</h1>
</header>
```

### 2. `nav`：导航区域

放菜单链接，告诉用户“去哪儿”。

```html
<nav>
  <a href="#home">首页</a>
  <a href="#about">关于我</a>
  <a href="#contact">联系我</a>
</nav>
```

### 3. `main`：页面主要内容

一个页面通常只放一个 `main`。

```html
<main>
  <p>这里是页面的主要内容。</p>
</main>
```

### 4. `section`：内容分区

适合“个人简介”“技能列表”“学习计划”这类主题分块。

```html
<section>
  <h2>个人简介</h2>
  <p>我正在学习 HTML。</p>
</section>
```

### 5. `article`：独立内容块

适合新闻、博客、帖子、评论等可以单独拿出来看的内容。

```html
<article>
  <h2>第1篇学习记录</h2>
  <p>今天我学会了语义化标签，网页结构更清楚了。</p>
</article>
```

### 6. `aside`：补充内容、侧边栏

适合提示信息、推荐内容、额外说明。

```html
<aside>
  <p>小提示：先学会整体结构，再追求美观。</p>
</aside>
```

### 7. `footer`：页脚

放版权、联系信息、说明等。

```html
<footer>
  <p>© 2025 全栈老赵</p>
</footer>
```

### 小练习

判断下面内容该放在哪个标签里：

- 网站菜单 → `nav`
- 页面底部版权 → `footer`
- 一篇博客正文 → `article`
- 页面主要介绍内容 → `main`

## 三、`div` 和语义化标签的关系：什么时候该用谁？

赵老师给你一个最实用的结论：

### 什么时候优先用语义化标签？

当这个区域有明确“身份”时，用语义化标签。

比如：

- 头部 → `header`
- 导航 → `nav`
- 主内容 → `main`
- 文章 → `article`
- 补充内容 → `aside`
- 页脚 → `footer`

它们的价值不在“更高级”，而在“更清楚”。

### 什么时候用 `div`？

当你只是想分组，但没有特别含义时，用 `div` 就行。

```html
<div class="card">
  <div class="card-title">标题</div>
  <div class="card-body">内容</div>
</div>
```

### 决策小口诀

- 有名字、有职责，用语义化标签
- 只负责包一层、没特殊含义，用 `div`
- 一段文字里想单独标记一个词，用 `span`

### `span` 也顺手记一下

`span` 是行内标签，常用于包住一小段文字，不会单独换行。

```html
<p>我是 <span>新手</span>，正在学习 HTML。</p>
```

赵老师式提醒：**别一上来全用 `div`，先想清楚每块内容是什么。**

## 四、把一个页面改写成语义化结构：从“能看”到“好懂”

原来你可能会写成这样：

```html
<div class="top">
  <h1>我的个人主页</h1>
  <div class="menu">
    <a href="#">首页</a>
    <a href="#">关于我</a>
  </div>
</div>

<div class="content">
  <div class="about">
    <h2>关于我</h2>
    <p>我是一个正在学习前端的新手。</p>
  </div>
</div>

<div class="bottom">
  <p>版权信息</p>
</div>
```

改成语义化结构后，会更清楚：

```html
<header>
  <h1>我的个人主页</h1>
  <nav>
    <a href="#">首页</a>
    <a href="#">关于我</a>
  </nav>
</header>

<main>
  <section>
    <h2>关于我</h2>
    <p>我是一个正在学习前端的新手。</p>
  </section>
</main>

<footer>
  <p>版权信息</p>
</footer>
```

你会发现：

- 头部就是 `header`
- 菜单就是 `nav`
- 主要内容就是 `main`
- 内容分块可以用 `section`
- 底部就是 `footer`

这就是语义化的价值：**结构一眼清楚。**

### 小练习

把你之前写过的一个简单网页，重新分成：

- `header`
- `nav`
- `main`
- `section`
- `footer`

不用追求复杂，先把区域名称写对。

# 第11章：常见错误与排查思路——新手最容易卡住的地方

学到这一章，很多同学都会遇到同一个问题：**代码写了，页面却不显示，或者显示得乱七八糟**。别急，这不是你“学不会”，而是新手必经的排错阶段。赵老师先提醒你一句：**网页报错不可怕，可怕的是一上来就乱改。先冷静，再按步骤查。**

这一章的目标很简单：让你学会自己找问题、自己修问题。以后遇到“图片不显示”“链接打不开”“表单没反应”，你不需要慌。记住一句话：**先看标签，再看路径，最后看浏览器反馈。**

## 一、先看标签：有没有闭合，嵌套顺不顺

HTML 最常见的坑，就是**标签忘了关**，或者**嵌套顺序写错**。浏览器虽然宽容，但不代表不会出问题。

### 1. 常见错误：标签没闭合

错误示例：

```html
<p>这是第一段
<p>这是第二段</p>
```

第一段 `<p>` 没有关闭，页面结构可能被打乱。

修正示例：

```html
<p>这是第一段</p>
<p>这是第二段</p>
```

### 2. 常见错误：嵌套顺序错了

错误示例：

```html
<strong><em>加粗又倾斜</strong></em>
```

记住一句话：**谁后开，谁先关**。

修正示例：

```html
<strong><em>加粗又倾斜</em></strong>
```

### 3. 怎么自查？

按这个顺序检查：

1. 每个开始标签后面有没有对应结束标签  
2. 关闭顺序对不对  
3. 是否少写了 `>`、`/` 或引号  
4. 缩进是否整齐，方便看层级  

赵老师提醒你：**HTML 不是猜谜语，先排整齐再判断。**

---

## 二、再看路径：图片、链接、文件名是不是写对了

图片不显示、链接打不开，很多时候都和路径有关。新手最容易在这里卡住，因为看起来差不多，实际上差一个字符就找不到文件。

### 1. 图片不显示，先查这三项

错误示例：

```html
<img src="images/photo.jpg">
```

如果图片不在 `images` 文件夹里，就不会显示。文件名写错也一样找不到。

修正示例：

```html
<img src="./images/photo.jpg" alt="我的照片">
```

先检查：

- 图片文件名对不对
- 后缀名对不对，比如 `.jpg`、`.png`
- 路径有没有写错

### 2. 链接打不开，先查 `href`

错误示例：

```html
<a hrf="https://www.example.com">去看看</a>
```

这里属性名写错了，应该是 `href`。

修正示例：

```html
<a href="https://www.example.com">去看看</a>
```

如果是本地页面跳转，也要检查文件名和路径：

```html
<a href="./about.html">关于我</a>
```

### 3. 目录结构要先看清

```text
my-site/
├── index.html
├── about.html
└── images/
    └── photo.jpg
```

当前页面是 `index.html` 时，找同级的 `about.html`：

```html
<a href="./about.html">关于我</a>
```

找图片：

```html
<img src="./images/photo.jpg" alt="我的照片">
```

如果直接写网址，这就是绝对路径：

```html
<a href="https://www.baidu.com">百度</a>
```

赵老师式提醒：**路径问题不要猜，直接去文件夹里看。你看到什么，就写什么。**

## 三、最后看浏览器反馈：刷新、地址栏、页面表现都要看

很多新手写完代码，只顾看效果，不看页面反馈。其实浏览器和编辑器都能帮你排查问题。

### 1. 先刷新，再确认是不是旧页面

有时候你改了代码，但浏览器还在显示旧内容。先试试普通刷新，必要时强制刷新。  
不要一看到页面没变，就立刻怀疑代码没生效。

### 2. 先看地址栏和页面表现

你可以这样排查：

- 地址栏是不是打开了正确的文件
- 页面有没有完全空白
- 文字能不能正常显示
- 图片是不是裂开了
- 链接点了之后有没有跳转

如果某个部分不正常，就先盯住这个部分，不要一上来就判断“整个网页坏了”。

### 3. 再看代码本身

重点检查这几个地方：

- 标签有没有成对
- 属性有没有写全
- 引号有没有配对
- 文件名有没有写错

很多问题其实都出在这些小地方。赵老师提醒你：**不是你不会，而是少了一个字母自己没发现。**

## 四、表单没反应，先别急着怪表单

纯 HTML 里的表单主要负责收集数据，真正提交后怎么处理，通常还需要后端配合。所以先检查最基础的结构有没有写对。

重点看这几项：

- `form` 标签有没有写完整
- `action` 是否有目标地址
- `method` 是否写对
- `input` 有没有写 `name`
- `button` 是否是提交按钮

可直接复制的示例：

```html
<form action="/submit" method="post">
  <input type="text" name="username" placeholder="请输入姓名">
  <button type="submit">提交</button>
</form>
```

赵老师式提醒：**表单不是“点了就自动有结果”，它更像一个装信息的盒子。** 盒子装好了，还得有人来接。

你可以把下面这套流程记下来，写 HTML 时很实用：

1. **看标签**：有没有闭合，嵌套顺序对不对  
2. **看属性**：`href`、`src`、`alt`、`action` 有没有写对  
3. **看路径**：相对路径、绝对路径有没有混乱

5. **看浏览器**：刷新后有没有变化，页面哪里异常  
6. **看结构**：内容是不是放错位置了  

这套方法不花哨，但很管用。新手最怕的不是出错，而是不知道从哪里开始查。你只要按这个顺序来，问题通常很快就能缩小范围。

```html
      <p>也可以访问我的 <a href="https://example.com" target="_blank">个人主页</a>。</p>
    </section>

    <!-- 留言表单 -->
    <section>
      <h2>给我留言</h2>
      <form action="#" method="post">
        <p>
          <label for="name">你的名字：</label>
          <input type="text" id="name" name="name">
        </p>
        <p>
          <label for="message">留言：</label>
          <textarea id="message" name="message"></textarea>
        </p>
        <button type="submit">发送</button>
      </form>
    </section>
  </main>
</body>
</html>
```

这份模板里已经用到了 `head`、`body`、标题、段落、链接、列表、表格、表单、语义标签等关键知识。  
赵老师式提醒：**先学会用，再慢慢理解。** 现在最重要的不是背定义，而是能把页面跑出来。

## 五、自查清单：一项一项打勾检查

写完后，别急着关页面，先照着这份清单检查一遍。

### 1. 文档结构
- [ ] 有没有 `<!DOCTYPE html>`
- [ ] 有没有 `<html>`、`<head>`、`<body>`

### 2. 标题和段落
- [ ] 标题是不是用了 `<h1>` 或 `<h2>`
- [ ] 介绍是不是用了 `<p>`

### 3. 列表和表格
- [ ] 列表是不是用了 `<ul>` 和 `<li>`
- [ ] 表格是不是用了 `<table>`、`<tr>`、`<th>`、`<td>`

### 4. 链接和图片
- [ ] 超链接是不是用了 `<a>`
- [ ] 如果用了图片，`src` 是否正确
- [ ] 图片的 `alt` 有没有写
- [ ] 路径分清了吗：本地文件多半用**相对路径**，网站地址是**绝对路径**

### 5. 表单
- [ ] 有没有 `<form>`
- [ ] 输入框是不是用了 `<input>`
- [ ] 文本框是不是用了 `<textarea>`
- [ ] `label` 和 `id` 是否对应
- [ ] 有没有写 `action` 和 `method`，先知道它们是提交表单用的就行，不用深入后端

### 6. 语义标签和常见属性
- [ ] 有没有合理使用 `header`、`main`、`section`
- [ ] 有没有用到常见属性，比如 `href`、`src`、`alt`、`target`、`name`

### 7. 注释
- [ ] 有没有写注释帮助自己看懂结构

例如：

```html
<!-- 这是兴趣区 -->
```

赵老师式提醒：**检查不是挑毛病，是帮你少走弯路。** 新手最常见的问题，不是不懂，而是写完没回头看。
