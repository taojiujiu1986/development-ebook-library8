# 第1章 第1章 CSS 是什么：先把网页从“能显示”变成“能看”

## 开篇：先别急着背语法，先弄明白它管什么
你已经会一点 HTML 了，说明你能把网页“搭起来”。但新手很快就会发现：内容有了，页面却很素，标题和正文差不多，按钮像灰块，图片和文字也挤在一起。

这时候就轮到 CSS 出场了。你可以把它理解成网页的“装修工”：**HTML 管结构，CSS 管样子。** HTML 决定页面里有什么，CSS 决定它们长什么样、放在哪里、彼此隔多远。

老赵先提醒你一句最有用的话：**先把“样子”这件事做稳，页面就已经能提升一大截。** 后面学选择器、字体、边距、布局，都是围着这个目标转。

## CSS 到底能解决什么问题
CSS 不是为了炫技，主要就是解决几类最常见的页面问题：

- **字体与字号**：让标题更醒目，正文更好读；
- **颜色与背景**：让重点更突出，页面有层次；
- **间距**：让内容别挤在一起，看起来更整洁；
- **布局**：让元素排得更合理，不再乱成一团。

比如一个商品展示页，没有 CSS 时通常只是商品名、价格、按钮一行行往下排；加上 CSS 后，标题更大，价格更醒目，按钮更像按钮，模块之间有空隙，页面立刻就像个正常网站了。

所以学 CSS，不是为了背术语，而是为了回答一个问题：**这个页面哪里不好看，我怎么把它改顺眼？**

## HTML 和 CSS 分工别混
很多新手会把样式直接写进 HTML，短期能跑，长期很难维护。

- **HTML**：写“这是什么”，比如标题、段落、图片、列表；
- **CSS**：写“它长什么样”，比如颜色、大小、间距、对齐方式。

你可以把 HTML 想成房子的户型图，把 CSS 想成装修方案。户型图管结构，装修管外观，别混着来。

## 没有 CSS 的页面，通常哪里不顺眼
新手页面难看，通常就这几类问题：

1. **字体太单一**：标题和正文没重点；
2. **行距太挤**：一段文字压在一起，读着累；
3. **颜色太乱**：重点不突出，层次不清；
4. **间距不对**：元素贴太近，显得拥挤；
5. **布局散乱**：图片、文字、按钮各站各的。

这些问题基本都靠 CSS 解决。以后你做个人主页、简介页、商品页，只要把这些基础问题处理好，页面观感就会明显不一样。

## CSS 能先学会哪几件最值钱的事
入门阶段别贪多，先抓住最常用的基础能力：

- **字体字号**：先让页面读起来舒服；
- **行高**：让文字别挤成一团；
- **文本对齐**：让标题、按钮、卡片更规整；
- **颜色与背景**：建立视觉重点；
- **边框**：区分模块边界；
- **内外边距**：控制元素之间的呼吸感；
- **display 和基础布局**：让元素按你想要的方式排列。

页面从“能显示”变成“能看”，靠的就是这些基础属性的组合。

## 老赵式提醒：别急着背，先想用途
新手最容易踩的坑，就是把 CSS 学成语法默写。记了一堆属性，却不知道它们解决什么问题，真到做页面时还是不会用。

老赵的建议很简单：**每学一个属性，先问自己一句——它是用来解决什么观感问题的？**  
比如行高是让文字更松一点，边距是让模块别挤在一起，背景是让区域更有区分度。用途想明白了，语法就是顺手的事。

## 先记住这条路线
你现在不用一下子掌握全部 CSS。第一步先把“网页为什么需要 CSS”想明白：**HTML 负责把东西摆出来，CSS 负责把它们整理好、打扮好。**

接下来我们就要进入实操了：**CSS 怎么引入到页面里，怎么真正开始改样式。** 这一步学会了，你才算真正从“会写 HTML”走向“会做页面”。

# 第2章 第2章 CSS 怎么引入：三种方式，先学会最常用的那种

## 开篇引入：样式写好了，怎么让页面真的变好看？

上一章你知道了，CSS 负责网页的“样子”。可新手最常遇到的事是：**我明明写了样式，页面怎么一点变化都没有？**

多数时候不是属性写错，而是 **CSS 没有正确引入页面**。  
这一章老赵带你把这件事一次弄明白。先记住一句最实在的话：

**先让样式生效，再谈写得好不好。**

我们先讲三种引入方式，再说为什么实际项目更推荐外部 CSS 文件，最后把新手最容易踩的坑捋一遍。你把这章吃透，后面学选择器、字体、盒模型会顺很多。

---

## 一、三种引入方式分别是什么？

CSS 引入 HTML，常见就三种：**内联样式、内部样式表、外部样式表**。  
先不用死记概念，先记它们分别“写在哪里”。

### 1）内联样式：直接写在标签上

把样式写进某个 HTML 标签的 `style` 属性里：

```html
<p style="color: red; font-size: 18px;">这行字会变红</p>
```

特点很直接：**写在哪儿，管哪儿。**  
适合临时测试，尤其是快速确认某个属性有没有效果时很方便。

但问题也明显：样式散在各个标签里，页面一多就难维护，后面统一修改会很痛苦。

**适合场景：**
- 临时调试
- 少量一次性样式
- 快速验证属性效果

**不推荐场景：**
- 正式页面
- 需要复用的样式
- 后面还要改版的项目

赵老师经验提醒：**内联样式不是不能用，是别把它当主力。**

---

### 2）内部样式表：写在 HTML 的 `<style>` 里

把 CSS 写在 HTML 的 `<head>` 中：

```html
<head>
  <style>
    p {
      color: blue;
      font-size: 16px;
    }
  </style>
</head>
```

这种方式比内联样式整洁，样式集中在一个地方。做单页练习时很方便，打开一个文件就能看到结构和样式。

它的局限也明显：**HTML 和 CSS 还是混在一起**。页面一多，就得每个文件重复写，维护成本会升高。

**适合场景：**
- 单页小练习
- 原型页面
- 小 demo 演示

---

### 3）外部样式表：把 CSS 单独放到 `.css` 文件里

这是实际开发里最常用、最推荐的方式。  
把样式写到单独的 CSS 文件中，再通过 `<link>` 引入：

```html
<link rel="stylesheet" href="style.css">
```

这样 HTML 负责结构，CSS 负责样式，分工清楚，也更好维护。  
你后面做个人主页、商品展示页，基本都会靠它。

**适合场景：**
- 正式项目
- 多页面网站
- 需要复用样式、统一风格的页面

---

## 二、为什么实际开发更推荐外部 CSS 文件？

不是因为“规范上这么写”，而是它确实更好用。

### 1）结构和样式分离，页面更清爽

HTML 只管内容，CSS 只管样子。  
以后查问题时，不用一边翻标签一边翻样式，思路更清楚。

### 2）样式可以复用

比如首页、商品页、个人主页都要用同一种按钮风格，你只写一个 CSS 类名，全站都能用。  
比每个页面复制一遍样式靠谱，也更不容易出错。

### 3）后期修改方便

把标题字体从 24px 改成 28px，只改一个 CSS 文件，所有引用它的页面都会更新。  
这就是外部 CSS 的价值：**一处修改，多处生效。**

### 4）更符合实际项目习惯

新手先学外部 CSS，后面写项目基本就靠它。  
内联和内部样式不是没用，而是更像临时工具，不是主力方案。

---

## 三、`link` 标签怎么引入 CSS？路径怎么写？

这是最该动手练的一块。

### 1）标准写法

在 HTML 的 `<head>` 里加：

```html
<link rel="stylesheet" href="style.css">
```

意思是：把当前 HTML 连接到 `style.css` 这个样式文件。

### 2）如果 CSS 文件在 `css` 文件夹里

目录结构如果是：

```txt
project/
├── index.html
└── css/
    └── style.css
```

HTML 里就写：

```html
<link rel="stylesheet" href="css/style.css">
```

### 3）路径怎么判断？

老赵给你一个最实用的判断方法：

- **同级目录**：直接写文件名，比如 `style.css`
- **子目录**：写文件夹名 + 文件名，比如 `css/style.css`
- **上级目录**：用 `../` 往上走，比如 `../style.css`

### 4）最容易错的地方

- 文件名拼错：`style.css` 写成 `styles.css`
- 路径多写或少写文件夹
- 扩展名漏写
- `link` 标签没放到 `<head>` 里

老赵经验提醒：**新手第一次样式不生效，十有八九先查路径。**

---

## 四、`style` 标签适合什么场景？

很多人会问：既然外部文件最好，那 `style` 标签是不是没用？  
不是，它有用，但要用对地方。

### 适合的场景

#### 1）单页小练习
页面内容少，临时写一点样式放在 `<style>` 里很方便。

#### 2）快速测试
想试颜色、字号、边距效果，放进 `<style>` 比来回切文件快。

#### 3）少量特殊样式
某个页面只需要额外补几条样式，用 `style` 也能临时处理。

### 不太适合的场景

- 大项目
- 多页面复用
- 团队协作开发

记住一句话：**`style` 标签是方便，不是主方案。**

---

## 五、新手常见坑点提醒：样式没生效先查这几个地方

这一节很重要，很多人卡半天，其实就是几个低级问题。

### 1）页面完全没变
先检查：
- `href` 路径对不对
- 文件名是不是写错了
- 后缀是不是 `.css`
- `link` 是否放在 `<head>` 里

### 2）CSS 文件明明写了，页面还是老样子
先检查：
- 选择器有没有选中元素
- 同名样式是不是被别的规则覆盖了
- CSS 语法有没有少分号、少括号

先写一个最简单的规则测试，比如：

```css
p {
  color: red;
}
```

如果这都不生效，就别急着加复杂样式，先把基础通了。

### 3）我改了样式，浏览器却没更新
先考虑：
- 是否是缓存
- 是否加载了旧文件

处理方法：
- 强制刷新页面
- 用无痕窗口试一下
- 临时改一下 CSS 文件名再引入

赵老师经验建议：**开发时别靠猜，浏览器没变，不一定是你没写对，也可能是缓存还在捣乱。**

### 4）同样的写法，别的元素有效，这个元素没反应
先看：
- 这个元素是不是行内元素
- 这个属性是否适合当前元素

后面学到 `display` 时，你会更明白为什么有些属性看着写了，效果却不对。

---

## 六、老赵给你的实战建议：先把“能引入”练熟

学 CSS 引入，不是为了背三种写法，而是为了做到一件事：  
**你能稳定地把样式加到页面上，并知道为什么生效。**

老赵建议你现在就做个小练习：

1. 新建 `index.html`
2. 新建 `style.css`
3. 在 HTML 里用 `<link>` 引入
4. 先写一个简单规则：

```css
p {
  color: #333;
  font-size: 18px;
}
```

5. 页面里放一段 `<p>` 文本
6. 刷新查看效果

如果没变化，就按这个顺序查：

- 路径
- 文件名
- `link` 标签位置
- 选择器有没有选中元素
- 浏览器缓存

这套习惯很重要，后面学选择器、盒模型、布局都能继续用。

---

## 本章小结：先把入口打通，后面才谈美化

这一章你只要抓住三件事：

- **内联样式**：写在标签上，临时方便，不适合长期维护
- **内部样式表**：写在 `<style>` 里，适合小练习和快速测试
- **外部样式表**：写在独立 CSS 文件里，实际开发最推荐

再记一句最实在的话：  
**新手样式不生效，先查引入路径，再查文件名，再查选择器，最后再看缓存。**

下一步就可以开始学选择器、类名和 ID 了。  
那才是真正把样式准确打到目标元素上的关键。

# 第3章 第3章 选中谁来改样式：选择器、类名、ID、继承与层叠

## 开篇引入：CSS 先解决一个最现实的问题——“我想改谁？”

前面我们知道，CSS 是给网页加样式的。但新手最容易卡住的，不是“属性怎么写”，而是“这条样式到底该给谁生效”。

这章要解决的核心，就是**选中元素**。先准确找到目标，后面的字体、颜色、边距才有意义。选错了，样式要么不生效，要么改了一大片，页面直接乱套。

老赵带新人时常说：**先学会找人，再学会修饰人。**

---

## 一、基础选择器：标签、类、ID，到底怎么选？

### 1. 标签选择器：适合“全体统一处理”

标签选择器直接写标签名，比如：

```css
p {
  color: #333;
}
```

意思是：页面里所有 `p` 标签都变成深灰色。

**适合：**
- 给全站某类标签打基础样式
- 统一段落行高、链接默认颜色

**优点：**简单直接，适合打底。  
**缺点：**范围太大，容易误伤。

新手常图省事直接写标签选择器，不是不能用，但要记住：**标签选择器适合打底，不适合精修。**

---

### 2. 类选择器：新手最常用、最值得练熟

类选择器写法是 `.name`，比如：

```css
.card {
  border: 1px solid #ddd;
  padding: 16px;
}
```

HTML 里这样用：

```html
<div class="card">内容</div>
```

类名可以重复使用，一个页面里多个卡片都能用同一个 `card` 类。

**适合：**
- 按模块复用样式
- 常见命名：`.btn`、`.title`、`.card`、`.avatar`

入门阶段，页面大多数样式都应该靠类来搭。做个人主页、商品卡片，基本都离不开它。

**赵老师建议：**  
> 大多数入门样式，优先用类，不要一上来就靠标签乱写。

---

### 3. ID 选择器：能用，但别滥用

ID 选择器写法是 `#id名`，比如：

```css
#header {
  background: #f8f8f8;
}
```

HTML：

```html
<div id="header">头部</div>
```

**特点：**
- 一个页面里通常只出现一次
- 适合唯一元素
- 优先级比类高

**适合：**
- 页面中确实唯一的区域
- 比如 `header`、`footer`、`main`

新手常误以为 ID “更强”就到处用。问题是：**ID 太强，后面覆盖样式更麻烦。**  
入门阶段记住一句话：**类是主力，ID 是少数特殊场景。**

---

## 二、类名与 ID 的区别：什么时候用哪个？

简单记：

- **类名**：可复用，适合组件、模块、按钮、卡片
- **ID**：唯一，适合页面中的单个区域

### 一个简单判断标准

如果你想的是：
- “这个样式可能出现在多个地方” → 用类
- “这个东西整页只有一个” → 可以考虑 ID

比如商品列表里的每个商品卡片，肯定是多个，就该用类；页面顶部的头部区域，必要时可以用 ID，但通常类也够用。

### 赵老师经验式建议

> 做项目时，先用类把页面搭起来。  
> 除非你特别确定这个元素唯一，而且有明确用途，否则别习惯性上 ID。  
> 入门期最稳的做法是：**80% 用类，ID 尽量少用。**

---

## 三、后代选择器、并集选择器：怎么把范围缩小？

### 1. 后代选择器：只管“某个区域里的某个元素”

写法是空格：

```css
.article p {
  line-height: 1.8;
}
```

意思是：只给 `.article` 里面的 `p` 设置行高。

**适合：**
- 文章区里的段落
- 卡片里的按钮
- 某个模块内部的标题

它解决的问题是：**同一个标签在不同区域，样式不一样。**

比如页面里两块 `p`：
- 文章正文里的段落，要更松一点
- 侧边栏里的提示文字，要更紧凑一点

这时就不能只写 `p`，而要用 `.article p`、`.sidebar p` 这种方式把范围缩住。

---

### 2. 并集选择器：多个对象一起改

写法用逗号：

```css
h1, h2, h3 {
  font-weight: bold;
}
```

意思是：`h1`、`h2`、`h3` 都用同样规则。

**适合：**
- 多个元素共享同一套样式
- 比如标题统一颜色，按钮统一圆角

并集选择器很适合做“统一动作”，不用一个个写。

---

### 3. 常见组合写法

比如：

```css
.card .title {
  font-size: 18px;
  color: #222;
}
```

表示：只改卡片里的标题。  
这类写法很适合做模块化页面。

**提醒：**  
选择器别写得太长。像 `.main .content .list .item p span` 这种虽然能用，但维护很痛苦，自己过两天都不一定看得懂。

---

## 四、继承、层叠、优先级：为什么样式会自己“变来变去”？

这三个概念放在一起看最省事。记住一个判断链：**先看继承，再看层叠，最后看优先级。**

### 1. 继承：父元素会把一部分样式带给子元素

比如给父元素设置字体颜色：

```css
body {
  color: #333;
}
```

很多子元素会默认继承这个颜色。

**常见可继承：**
- `color`
- `font-size`
- `font-family`
- `line-height`

**一般不继承：**
- `border`
- `margin`
- `padding`
- `background`

你可以把继承理解成：**父元素给子元素顺手带过去的基础风格。**

这在实际页面里很有用。比如先给 `body` 统一深灰色，局部再改成别的颜色，页面就容易整体协调。

---

### 2. 层叠：多条规则会一起作用，最后留下一个结果

同一个元素，可能同时被标签选择器、类选择器、后代选择器选中。CSS 会把这些规则叠在一起，最后算出一个最终样式。

所以新手常说：“我明明写了，怎么没生效？”  
很多时候不是没写，而是**被更靠后的或更强的规则覆盖了**。

---

### 3. 优先级：谁更强，谁说了算

大致记法：

- `ID` > `类` > `标签`
- 更具体的选择器通常更强
- 同级别时，**后写的覆盖先写的**

比如：

```css
p { color: blue; }
.text { color: red; }
#main { color: green; }
```

如果某个段落同时满足这些规则，通常 `#main` 更容易生效。

**最实用的判断顺序：**
1. 有没有写对选择器？
2. 这个元素有没有真的匹配到？
3. 是不是被更高优先级覆盖了？
4. 同级规则里，是不是后面的覆盖前面的？

---

## 五、冲突时怎么判断谁生效？先查这三样

如果样式没按预期出现，别急着怀疑浏览器，先按这个顺序查：

### 1. 先看有没有选中
确认 HTML 里的类名、ID 是否拼写正确。  
很多问题根本不是 CSS 错了，而是 `class="card"` 写成了 `class="crad"`。

### 2. 再看优先级够不够
`p`、`.box p`、`#header p`，通常后者更容易赢。  
如果同一个元素被多条规则命中，先判断哪条更强。

### 3. 最后看是不是后写覆盖了先写
同样优先级时，后面的规则会覆盖前面的。  
比如先写了 `.btn { color: red; }`，后面又写了 `.footer .btn { color: white; }`，后者很可能把前者盖掉。

**赵老师的经验式避坑建议：**  
> CSS 里十次出问题，八次都在这三步里：写错了、没选中、被覆盖。先查这三项，别上来就乱改一通。

---

## 六、新手常见坑点：少走弯路

### 坑 1：选择器写得太宽
比如直接写：

```css
p {
  margin: 0;
}
```

结果全站段落都没了间距。  
**建议：**尽量把样式限制在模块内部，比如 `.article p`。

### 坑 2：ID 滥用
很多新手觉得 ID 很强，处处都用 `#xxx`。  
后果是：后面想复用样式很难，覆盖也麻烦。

**赵老师建议：**  
> 先用类把页面做出来，再考虑是否需要 ID。别把 ID 当万能钥匙。

### 坑 3：样式被覆盖，却找不到原因
最常见的办法不是瞎删，而是按“有没有选中—优先级够不够—是不是后写覆盖”一步步排。

---

## 七、一个很小的实战例子：同一套样式，局部再改

比如你有一个文章页：

```html
<div class="article">
  <h2>标题</h2>
  <p>正文内容</p>
</div>

<div class="sidebar">
  <p>侧边栏提示</p>
</div>
```

你可以先统一基础样式：

```css
body {
  color: #333;
  font-size: 16px;
  line-height: 1.8;
}

.article p {
  color: #444;
}

.sidebar p {
  color: #888;
  font-size: 14px;
}
```

这里能看出三件事：
- `body` 先把整页底色和字色打好
- `.article p` 只管文章正文
- `.sidebar p` 单独改侧边栏

这就是 CSS 最常见的写法：**先统一，再局部修正。**

---

## 结尾小结：先学会“选中”，再谈“变好看”

这一章真正要拿下的，不是几个选择器名字，而是这套思路：

- **标签选择器**：统一基础样式
- **类选择器**：模块化复用，最常用
- **ID 选择器**：少量唯一元素使用
- **后代选择器**：限制作用范围
- **并集选择器**：多个元素一起处理
- **继承与层叠**：解释样式为什么会传递、为什么会覆盖
- **优先级**：冲突时谁生效

### 赵老师给你的行动建议

1. 写样式先用类，少用 ID  
2. 不要把选择器写得太长太绕  
3. 样式出问题先查“有没有选中”，再查“优先级”  
4. 多练“同一个标签在不同区域用不同样式”的场景  
5. 遇到覆盖问题，先按“选中—优先级—后写覆盖”三步排查

你把“选中谁来改”这件事搞明白了，后面的字体、颜色、边距、布局才真正有地方落脚。下一章，我们就可以开始把元素修得像样一点了。

# 第4章 第4章 让字和内容看起来顺眼：字体、字号、行高、对齐与排版基础

网页刚写出来时，最常见的问题不是没功能，而是“看着累”：标题像普通文字，正文挤成一团，按钮里的字偏上偏下。老赵做项目时一直强调：**先把字排顺，再谈页面高级感。** 这一章就先解决文字样式的基础问题，把标题、正文和说明文字排得更清楚、更舒服。**本章先讲文字排版；下一章再讲颜色、背景和边框。**

---

## 一、`font-family`：字体怎么选，页面才不别扭？

`font-family` 用来设置字体。新手先记住一条：**优先选清晰、常见、不会跑样的字体**，先保证好读，再谈风格。

```css
body {
  font-family: "Microsoft YaHei", "PingFang SC", Arial, sans-serif;
}
```

这类写法的意思是：先用常见中文字体，不行再往后退，最后用无衬线字体兜底。这样兼容性更稳。

赵老师的经验建议：

- 正文优先用系统常见字体，别追求花里胡哨。
- 整页尽量统一字体，别标题一套、正文一套、按钮又一套。
- 不知道选什么时，先用默认无衬线字体，通常最保险。

如果文字看起来像“古早海报”或打字机风，多半是字体太怪了。入门阶段先求稳，页面自然就会顺眼很多。

---

## 二、`font-size`：字号不是越大越好，而是要有层级

`font-size` 决定文字大小，它最重要的作用不是“放大”，而是**把标题、正文、说明文字分出层级**。

```css
h1 { font-size: 28px; }
h2 { font-size: 22px; }
p  { font-size: 16px; }
small { font-size: 12px; }
```

这不是死规定，只是一个很好用的起点：标题比正文大，正文比说明文字更稳。

新手页面通常这样定更合适：

- 正文先从 `14px ~ 16px` 开始；
- 标题比正文大一档或两档就够了；
- 说明文字可以略小，但别小到看不清。

常见坑点：

- 字号过大，页面像在喊话；
- 所有文字一个大小，没有重点；
- 说明文字太小，尤其手机上很难读。

赵老师的建议很直接：**先把正文做舒服，再把标题做醒目。**

---

## 三、`line-height`：行高决定你读起来累不累

`line-height` 控制一行文字和下一行文字之间的距离，作用就是给文字留呼吸空间。太小会挤，太大又会散。

```css
p {
  font-size: 16px;
  line-height: 1.6;
}
```

`1.5 ~ 1.8` 是正文常见范围，通常都比较稳。正文、说明文字都需要合适行高，标题则可以紧一点，不必像正文那样松。

如果一段说明文字很“压”，先别急着改颜色，**先把行高加大一点**，往往立刻就顺眼了。很多时候，行高比单纯加字号更能改善阅读感。

---

## 四、`text-align`：标题、按钮、卡片里最常用的对齐方式

`text-align` 控制文本水平对齐，最常见就是左对齐和居中对齐。它解决的问题很简单：**让内容更整齐、更容易看。**

```css
.title {
  text-align: center;
}
```

常见场景：

- 标题居中：适合首页标题、卡片标题、宣传语；
- 按钮文字居中：让按钮规整；
- 短文案居中：更像一个完整组件。

但如果是一大段正文，通常还是左对齐更舒服，因为起点统一，眼睛扫起来更轻松。

老赵的判断很简单：**短内容可居中，长内容优先左对齐，按钮文字尽量居中。**

---

## 五、`font-style`、`text-decoration`、`text-indent`、`white-space`：文字展示的小帮手

这些属性不是最核心，但很常用。

### 1. `font-style`：控制斜体

```css
em {
  font-style: italic;
}
```

通常用于强调、引语或少量特殊文字。不要为了“好看”把整页文字都斜掉，那只会更累。

### 2. `text-decoration`：控制下划线、删除线

```css
a {
  text-decoration: none;
}
```

最常见用途是处理链接。默认链接有下划线，有时会显得乱，可以按页面风格决定是否去掉。但去掉后一定要让它仍然像链接，不然用户不知道能点。

### 3. `text-indent`：首行缩进

```css
p {
  text-indent: 2em;
}
```

适合文章型内容，让段落更像正文。`2em` 很常见，大约就是缩进两个字宽。若是卡片式、列表式页面，不缩进往往更整洁。

### 4. `white-space`：控制空格和换行

```css
.code {
  white-space: pre;
}
```

常用于代码或需要保留原始换行的文本。普通正文一般不用特别改，默认就够了。记住一句：**别让不必要的换行把页面撑乱。**

---

## 六、正文、标题、按钮文案，怎么按场景设值？

光知道属性不够，关键是会用。老赵给你一套最容易上手的规则，直接照着调都行。

### 1. 正文怎么定

- 字体：常见无衬线字体；
- 字号：`14px ~ 16px`；
- 行高：`1.5 ~ 1.8`；
- 对齐：左对齐；
- 不要加太多装饰。

正文的目标只有一个：**让人看得轻松。**

### 2. 标题怎么定

- 字号比正文更大；
- 可以加粗；
- 短标题可居中；
- 适当留白，和正文拉开距离。

标题的目标是**先抓注意力，再带出内容层级。**

### 3. 按钮文案怎么定

- 字号不要太小；
- 文字尽量居中；
- 可以略加粗；
- 别加太夸张的字间距。

按钮里的字要做到一眼看懂、视觉稳定，不要让人找半天按钮在哪。

---

## 七、段落之间为什么要留白：别把所有空隙都当成行高问题

新手常把页面挤得很满，觉得只要行高够了就行。其实不对。**行高解决的是一段文字内部的呼吸感，`margin` 解决的是段落和段落之间的距离。**

### 1. 什么时候用行高

- 同一段里的多行文字；
- 正文阅读体验；
- 说明文字的舒适度。

### 2. 什么时候用 `margin`

- 标题和正文之间；
- 段落和段落之间；
- 头像和姓名之间；
- 模块和模块之间。

赵老师的经验是：**该靠行高的别硬加 `margin`，该靠 `margin` 的也别全指望行高。** 两者分工清楚，页面才会松紧得当。

---

## 八、新手常见坑点提醒：别让排版越调越乱

这一段很重要，很多人就是在这里翻车。

- 字体不要乱装。字体越多，页面越容易乱。先统一一种主字体，最多再配一种强调字体。
- 行高不要只看数字，不看视觉。字号变了、内容变了，效果也会变，要看读起来舒不舒服。
- 字间距不要给正文乱加。`letter-spacing` 适合短标题，不适合长正文。
- 下划线不是必须去掉。链接去掉下划线后，一定要用颜色、按钮样式或 hover 效果告诉用户这里能点。
- 别靠很多花活硬“救丑”。排版问题，九成能靠字号、行高、对齐和留白解决。

---

## 九、一个很实用的小练习：把页面文字排顺

如果你在做个人主页或商品展示页，可以按这个顺序来：

1. 先统一全站字体；
2. 给正文定一个舒服字号；
3. 给正文加合适行高；
4. 让标题和按钮更醒目；
5. 用居中或左对齐拉开层级；
6. 最后检查加粗和字间距有没有过头。

一个简单的效果思路：

- **标题**：大一点、可加粗、短内容可居中；
- **正文**：16px 左右、行高舒服、左对齐；
- **按钮文字**：居中、略粗、别太小；
- **说明文字**：比正文小一点，但要看得清。

很多页面不是缺高级效果，而是缺清楚的文字层级。先把文字排顺，页面就已经比原来好很多了。

---

## 本章小结

这一章你要记住的，不是属性名有多少，而是它们各自解决什么问题：

- `font-family`：统一字体风格，保证清晰稳妥；
- `font-size`：拉开标题、正文、说明的层级；
- `line-height`：让文字更容易读；
- `text-align`：让标题、正文、按钮更整齐；
- `font-style`、`text-decoration`、`text-indent`、`white-space`：做基础文字展示控制；
- `margin`：给段落和模块留空白。

老赵给你的实战建议只有一句：**先把正文排顺，再把标题做醒目；先追求整洁，再追求风格。** 你只要能把一页字排得清楚、舒服，页面就已经从“能用”往“好看”迈了一大步。下一章，我们继续把颜色、背景和边框加进来，让页面开始真正有样子。

# 第5章 第5章 给页面加情绪：颜色、背景、边框怎么搭出基本好看

前面我们把文字排整齐了，页面还是容易像“黑字白底作业纸”。这一步，老赵带你把页面做出一点情绪：**用颜色、背景和边框，让内容有主次、有分区、有重点**，页面就能从“能看”变成“顺眼”。

新手最容易翻车的地方就两个：一是颜色一口气上太多，像调色盘撒了；二是背景、边框乱堆，结果比没加还乱。老赵的经验很简单：**先少，再稳，最后再点亮重点**。先学会把该强调的提出来，把该分开的隔开，你就已经超过不少刚入门的人了。

## 5.1 color：文字颜色先管住，页面就不会乱

`color` 管的是**文字颜色**。它首先不是装饰，而是**可读性工具**：让字更清楚，或者让重点更明显。

常见就三种用法：

1. **普通正文**：别总用纯黑，`#333`、`#444` 往往更舒服。  
2. **强调信息**：比如价格、标题、提示语，用醒目颜色突出。  
3. **状态提示**：成功、警告、错误，常配不同颜色，让用户一眼看懂。

```css
.title {
  color: #222;
}

.price {
  color: #e60012;
}

.note {
  color: #666;
}
```

颜色的目的不是“让页面热闹”，而是告诉用户：**谁是主角，谁是配角**。比如商品页里，标题深一点，价格用强调色，说明文字就退后，不要抢戏。

### 新手常见坑点

- 字色太浅，看着费劲；
- 一页里颜色太多，眼睛很累；
- 只看“好不好看”，不看“清不清楚”。

### 赵老师的经验式建议

一页先控制在三类文字色就够了：主文字色、辅助文字色、强调色。别一上来就想着“每块都不一样”，大概率会乱。

## 5.2 background-color：背景色不是为了花，是为了分层

`background-color` 是**背景色**，主要作用不是漂亮，而是**把内容分开**，给内容“垫个底”。

常见场景很实用：

- 导航栏一块底色，和正文区区分开；
- 提示框一块浅色底，提醒用户这里是重点；
- 卡片一块白底，配合页面浅灰背景，层次就出来了。

```css
.notice {
  background-color: #f5f7fa;
}
```

它解决的是“内容挤在一起看不清”的问题。比如个人主页里，头像和简介放在白底卡片里，外层页面用浅灰底，模块边界一下就出来了。商品页也一样，商品卡片有底色，用户更容易扫到每个商品。

### 新手常见坑点

- 背景颜色太重，整页像色板；
- 背景和文字颜色太接近，看不清；
- 每个区域都换一种背景，页面失去统一感。

### 赵老师的经验式建议

先从浅灰、浅蓝、浅黄这种低刺激颜色练手。大面积背景尽量选浅色，背景色的任务是托内容，不是抢内容。高饱和色铺满页面，通常不会更高级，只会更吵。

## 5.3 background-image：先知道它干什么，别急着全页铺图

`background-image` 就是**给元素加背景图片**。新手阶段先记住它最常见的用途：

1. 页面顶部横幅  
2. 按钮或卡片的小装饰  
3. 轮播图、宣传图的底图  

```css
.banner {
  background-image: url("banner.jpg");
}
```

它主要解决的是“页面需要一点视觉氛围”的问题。比如活动页顶部放一张横幅图，能让页面更有主题感；卡片里加一点小背景图，也能增强识别度。

### 新手要注意

- 背景图不是内容本身，更像装饰层；
- 图片很花时，文字压上去要小心可读性；
- 大图别到处塞，页面会显得很重；
- 图片分辨率太低，页面马上就显得不专业。

老赵建议你先把**内容清楚**放在第一位。背景图只负责加一点气氛，不要把它当主角。个人主页、商品展示页里，背景图最常见的是封面区、活动区，不是全页乱铺。

## 5.4 border：边框负责说清楚“这里是一块”

`border` 是**边框**，作用很直接：**把一个区域圈出来**。它通常由三部分组成：

- 宽度：比如 `1px`
- 样式：比如 `solid` 实线、`dashed` 虚线
- 颜色：比如 `#ddd`

```css
.card {
  border: 1px solid #ddd;
}
```

### 边框在页面里的作用

- **分隔内容**：模块边界更清晰；
- **强调可点击区域**：按钮、标签、输入框常用；
- **增强秩序感**：比单靠空白更容易看懂结构。

比如商品卡片里，图片、标题、价格放在一起，没有边框时容易和旁边内容混成一片；加上一条浅边框，卡片立刻就站住了。再比如按钮，浅边框能让它看起来更像一个可操作的控件。

### 新手常见坑点

- 边框太粗，页面会显得很硬；
- 边框颜色太深，像每个盒子都套了黑框；
- 边框和背景太接近，等于白加。

### 赵老师的经验式建议

新手先从 `1px solid #ddd` 这种最稳的开始。先让页面规矩，再慢慢调整精致感。边框第一任务是“看得出来”，不是“抢眼”。

## 5.5 圆角与边框：卡片、按钮、标签为什么常一起出现

虽然本章重点是颜色、背景和边框，但圆角经常和边框一起用，因为**圆角能把生硬感降下来**。

```css
.card {
  border: 1px solid #eee;
  border-radius: 8px;
  background-color: #fff;
}
```

常见搭配很简单：

- **卡片**：白底 + 浅边框 + 圆角  
- **按钮**：底色 + 圆角 + 适当边框  
- **标签**：浅背景 + 小边框 + 小圆角  

```css
.btn {
  background-color: #1677ff;
  color: #fff;
  border: 1px solid #1677ff;
  border-radius: 6px;
}
```

你可以这么记：

- 边框：负责“有边界”
- 圆角：负责“没那么硬”
- 背景色：负责“有层次”

三者配合，页面就容易从“方块堆叠”变成“有秩序的模块”。

## 5.6 错误—修正对照：新手最容易翻车的几个地方

### 错误 1：颜色太多
```css
.box1 { color: red; }
.box2 { color: blue; }
.box3 { color: green; }
.box4 { color: orange; }
```

问题不是不能写，而是页面会很吵。

**修正思路：**
- 主色 1 个
- 辅助色 1 到 2 个
- 中性色负责大部分文字和背景

### 错误 2：文字和背景对比太弱
```css
.note {
  color: #ccc;
  background-color: #f0f0f0;
}
```

这种搭配看着就费劲。

**修正思路：**
- 浅背景配深文字
- 深背景配浅文字
- 正文先保证清楚

### 错误 3：边框和背景一起乱加
```css
.card {
  background-color: #333;
  border: 2px solid #000;
}
```

这种搭配会让页面压得很重。

**修正思路：**
- 背景浅，边框也浅
- 背景强，边框就弱一点
- 同一个区块里别堆太多视觉元素

### 错误 4：每个地方都想突出
结果最后没有重点，整页都在喊“看我”。

**修正思路：**
- 只突出最重要的一个点
- 其他内容尽量退后
- 让用户一眼知道先看什么

## 5.7 老赵的页面配色套路：先稳住，再美化

给简单主页或商品页做样式，按这个顺序来最不容易翻车：

1. **先定文字颜色**：正文深灰，标题更深，提示信息用强调色  
2. **再铺背景色**：页面整体浅底，模块用更浅或纯白  
3. **加边框分区**：卡片、输入框、标签先用 1px 浅边框  
4. **最后补圆角**：让页面柔和一点  
5. **检查整体对比**：能不能一眼看清重点内容  

这套方法不花哨，但很适合新手。先把“整洁”和“清晰”做到位，再谈风格。很多页面不是输在“不够酷”，而是输在“看不清、分不出、太乱”。

## 本章小结

这一章你要记住的核心就一句：**颜色、背景、边框的任务不是炫技，而是帮页面建立层次和重点。**

你现在应该能做到：

- 用 `color` 控制文字颜色；
- 用 `background-color` 做分区和层次；
- 知道 `background-image` 是干什么的；
- 用 `border` 给模块定边界；
- 结合圆角、背景、边框，做出卡片、按钮、标签这些常见样式；
- 避开颜色太多、对比太弱、乱搭边框这些新手坑。

### 课后动作建议

拿前面做过的一个简单页面，试着只改三处：

- 标题颜色
- 主内容区域背景色
- 一个卡片或按钮的边框与圆角

你会很快发现，页面不一定要“加很多东西”才会变好看，很多时候，**把颜色和边框用对了，就已经赢一半了**。

# 第6章 第6章 盒模型入门：内外边距、宽高与元素占位

## 开篇：为什么你明明写了宽高，页面还是乱了？

新手学 CSS，最常卡住的就是：**我都写了 `width` 和 `height`，怎么元素还是不听话？**  
按钮太挤、卡片间距忽大忽小、盒子一加 `padding` 就撑破页面，这些问题，背后基本都绕不开盒模型。

老赵先给你一句实话：**CSS 里的元素不是只看宽高，而是看它“实际占了多少地方”。**  
内容、内边距、边框、外边距，一起决定了元素最终的占位。你想把页面排整齐，先把这个规则搞明白。

---

## 一、content、padding、border、margin 四层盒模型到底是什么？

一个元素可以粗略看成四层：

### 1. content：内容区
最里面的区域，放文字、图片、按钮里的实际内容。比如商品卡片里的标题、价格、描述，都在这里。

### 2. padding：内边距
内容和边框之间的空白。它的作用很直接：**让内容别贴着边，看起来更松快。**

```css
button {
  padding: 10px 16px;
}
```

按钮文字不挤边，视觉就舒服很多。

### 3. border：边框
围住内容和内边距的一圈线，常用来做分隔和模块边界，比如卡片、输入框、按钮。

### 4. margin：外边距
元素外面的空白，用来控制它和别的元素之间的距离。  
一句话记：**padding 管里面，margin 管外面。**

```css
.card {
  margin-bottom: 16px;
}
```

这样卡片之间就不会挤在一起。

---

## 二、padding 和 margin 有什么区别？什么时候用哪个？

这个问题新手最容易混。

### padding：让自己内部更舒服
适合：

- 按钮文字别贴边
- 卡片内容别紧贴边框
- 输入框内部留白

```css
.card {
  padding: 16px;
}
```

### margin：让自己和别人保持距离
适合：

- 标题和正文分开
- 卡片和卡片之间隔开
- 模块之间留上下间距

```css
.title {
  margin-bottom: 12px;
}
```

### 老赵经验：先问“空白是给谁看的？”
- **内部体验**，多半用 `padding`
- **元素之间关系**，多半用 `margin`

你要是把它们用反了，常见症状就是：**里面还是挤，外面却空了一大块。**

---

## 三、为什么设置了 width 和 height，页面还是会变形？

默认情况下，`width` 和 `height` 主要管 **content 区域**，不管 `padding` 和 `border`。

```css
.box {
  width: 200px;
  height: 100px;
  padding: 20px;
  border: 5px solid #333;
}
```

你以为盒子总宽是 200px，但实际还要再加左右 `padding` 和 `border`，总宽度会更大。  
这就是很多布局“明明设了宽度，还是撑破”的原因。

### 页面为什么会怪？
通常有两种情况：

1. **盒子比你想的大了**  
   本来想做一个 200px 宽的卡片，结果加了 padding 和 border 后，比预期宽，父容器放不下，就挤歪了。

2. **多个盒子加起来超了**  
   两个并排卡片本来各 50%，再加上 padding、border，实际总和超过 100%，就会换行、错位，或者把布局撑散。

### 你要记住
页面真实占位要一起看：

- `width` / `height`
- `padding`
- `border`
- `margin`

尤其在一排布局里，盒子一旦算大了，就容易把别的元素挤下去。

---

## 四、box-sizing: border-box 为什么对新手特别有价值？

```css
.box {
  box-sizing: border-box;
}
```

它的作用是：**让 `width` 和 `height` 更接近你看到的最终盒子大小。**  
也就是说，`padding` 和 `border` 会算进你设定的宽高里，不再额外往外撑。

### 它的好处
1. 更好算  
2. 不容易撑破布局  
3. 特别适合卡片、表单、按钮

### 老赵建议
新手写页面时，常见盒子最好统一加上：

```css
* {
  box-sizing: border-box;
}
```

这样很多“加个 padding 页面就炸了”的问题能少一大半。

### 一个直观对比
同样一个卡片：

```css
.card-a {
  width: 240px;
  padding: 20px;
  border: 1px solid #ddd;
}

.card-b {
  width: 240px;
  padding: 20px;
  border: 1px solid #ddd;
  box-sizing: border-box;
}
```

`card-a` 默认情况下，实际宽度会比 240px 更大；  
`card-b` 会尽量保持在 240px 这个范围里。  
对新手来说，这个差别非常实用，尤其是做个人主页、商品卡片、表单输入框时，能少踩很多坑。

---

## 五、块级元素和行内元素在盒模型上有什么不同？

### 1. 块级元素
如 `div`、`p`、`h1`、`section`。

特点：

- 默认独占一行
- 可以设置 `width`、`height`
- 上下间距表现更直观

适合做页面容器、卡片、标题区、内容块。

### 2. 行内元素
如 `span`、`a`、`strong`。

特点：

- 默认不独占一行
- 更像“文字里的小零件”
- 不适合直接拿来做大盒子布局

### 说白了怎么理解？
- **块级元素**：更像一个可以单独摆放的盒子
- **行内元素**：更像贴在文字里的标签

### 新手常见情况
你给 `span` 写宽高，发现它不像 `div` 那样正常工作。  
所以记住一句话：**想做“盒子式布局”，优先用块级元素；想做文本里的小点缀，再用行内元素。**

---

## 六、一个小案例：把“难看”的卡片修整齐

先看一个常见写法：

```html
<div class="card">
  <h3>蓝牙耳机</h3>
  <p>轻便、续航久、适合日常通勤</p>
</div>
```

```css
.card {
  width: 240px;
  height: 80px;
  margin: 20px;
  padding: 20px;
  border: 1px solid #ddd;
}
```

问题会很明显：

- 标题和描述挤在一起
- 高度不够，内容可能顶出来
- `margin` 只管外部，内部还是挤
- 父容器窄一点时，布局还可能被撑乱

### 怎么修？

```css
.card {
  width: 240px;
  padding: 16px;
  border: 1px solid #ddd;
  margin-bottom: 16px;
  box-sizing: border-box;
}

.card h3 {
  margin: 0 0 8px;
}

.card p {
  margin: 0;
}
```

### 这个改法解决了什么？
- `padding` 让内容离边框有呼吸感
- `margin-bottom` 让卡片之间分开
- 去掉标题和段落默认外边距，避免浏览器自带间距把布局弄乱
- `box-sizing: border-box` 防止盒子一加 padding 就变大

这就是盒模型真正的用法：**不是背名词，而是把卡片、按钮、表单这些基础模块排顺。**

---

## 七、新手最常踩的三个坑，老赵帮你提前躲开

### 坑 1：所有空白都用 margin
结果按钮内部还是挤，模块之间却离太远。

**记住：**
- 里面松，用 `padding`
- 外面隔，用 `margin`

---

### 坑 2：盒子一加 padding 就撑破
尤其是 `width: 100%` 的元素，最容易出问题。

**避坑建议：**
- 优先统一 `box-sizing: border-box;`
- 写完模块后检查它有没有超过父容器
- 发现布局跑偏，先看是不是盒子实际宽度变大了

---

### 坑 3：margin 和 padding 用反
比如想让按钮文字别贴边，却写成了 `margin`，结果只是按钮外面空了，里面还是挤。

老赵的判断口诀很土，但管用：**里面松用 padding，外面隔用 margin。**

---

## 八、赵老师的实战检查清单：写盒子时先看什么？

每次写卡片、按钮、表单项，按这个顺序来：

1. **先看内容区够不够放**
2. **再加 padding**，让内部留白舒服
3. **需要边界感就补 border**
4. **最后调 margin**，控制和别的模块的距离
5. **如果一加 padding 就乱了，先怀疑 box-sizing**

老赵的习惯是：**先把单个模块做顺，再放回整页里看。**  
别一口气改十几个属性，不然很难知道到底是谁把页面搞乱了。

### 再补一句经验话
做商品卡片、个人简介卡片、登录框这类页面时，最容易出问题的不是颜色，而是**间距和占位**。  
所以别急着调花哨效果，先把盒子大小、内外边距、边框位置理顺，页面通常就已经比原来整洁很多了。

---

## 九、把盒模型和基础布局接起来看

盒模型不只是让单个盒子好看，它还会直接影响基础布局。

比如两个卡片并排：

```css
.card {
  width: 48%;
  padding: 16px;
  border: 1px solid #ddd;
  box-sizing: border-box;
  margin-bottom: 16px;
}
```

如果没考虑 padding 和 border，两个 48% 的卡片看起来能并排，实际一加边距就容易挤。  
这时候你就会发现：**布局不是单纯写个宽度就完事，还得把盒子实际占位算进去。**

这也是为什么老赵一直强调：先把盒模型弄明白，再去学 `display`、浮动、定位，后面才不会越学越乱。

---

## 本章小结：先会算盒子，页面才不会乱

盒模型要记住的一句话就是：**元素占位，不只看宽高，还要看内边距、边框和外边距。**

核心点再捋一遍：

- `content` 是内容
- `padding` 是内部留白
- `border` 是边界线
- `margin` 是外部间距
- `width` / `height` 默认主要管内容区
- `box-sizing: border-box;` 能减少撑破布局
- 块级元素和行内元素的盒模型表现不一样

### 赵老师给你的建议
1. 做页面时先统一用 `box-sizing: border-box;`
2. 加间距前先分清是“里面空”还是“外面隔”
3. 写完模块就检查有没有超出父容器
4. 先把卡片、按钮、表单这些基本盒子排整齐，再谈复杂布局
5. 遇到页面变形时，先查 `width`、`padding`、`border`、`margin`

下一步，你就可以带着盒模型思维继续学 `display` 和基础布局了。只要盒子算明白，页面美化就不再是瞎试，而是有章法地搭起来。

# 第7章 第7章 display 与基础布局：让元素排开、并排、换行

## 开篇引入：为什么你写的页面总是“一行一大坨”

新手写 CSS，最常见的不是颜色和字体，而是页面总排不顺：按钮挤成一团，图片一张张往下掉，导航栏歪歪扭扭。老赵告诉你，很多时候关键不在别处，而在 **display**。

你可以把 `display` 理解成：**这个元素到底怎么参与排版**。  
有的元素独占一行，有的跟别人并排，有的既能并排又能控制大小。先把这件事搞明白，后面做导航、卡片、列表都会顺手很多。

简单说，`display` 决定元素是“站一整排”，还是“跟别人排队”，还是“既能并排又能控尺寸”。这就是基础布局的起点。新手这一章不用追求高级布局，先把元素按预期排开，页面就已经能从“能用”往“像样”迈一步了。

---

## 1. display: block、inline、inline-block 到底差在哪？

### 1.1 block：默认就爱占一整行

块级元素的特点很简单：**独占一行**。  
像 `div`、`p`、`h1` 这类元素，通常会从左到右撑满父容器宽度。

**记住三点：**
- 会换行
- 能设置宽度、高度
- 上下左右间距都比较好控制

**适合做什么：**
- 页面大块区域
- 标题段落
- 卡片容器
- 导航栏外层结构

老赵经验：如果你想让一块内容“像个盒子”，先想到 `block`。比如商品卡片外层，很适合先用块级元素承载，再把图片、标题、价格分层放进去。

### 1.2 inline：跟文字一样排队

行内元素像文字的一部分，典型如 `span`、`a`、`strong`。  
它们不会强行换行，而是跟着当前文本流继续排。

**特点：**
- 不独占一行
- 通常不能直接设置宽度、高度
- 更适合文本中的小范围内容

**适合做什么：**
- 文本强调
- 标签、链接
- 小范围装饰

**常见坑点：**  
新手最爱把 `span`、`a` 直接当大盒子用，结果 `width`、`height` 没效果。记住：**行内元素不是按“盒子”那套来玩的。** 如果你希望它像按钮一样有面积，通常要改成 `inline-block`。

### 1.3 inline-block：既能并排，又像盒子

`inline-block` 是入门阶段很好用的属性。它既能像行内元素一样并排显示，又能像块级元素一样设置宽高。

**适合做什么：**
- 按钮
- 标签
- 小卡片
- 图文混排的小块

**理解方式：**
- 想并排：像 inline
- 想控制大小：像 block

老赵建议：做导航项、商品标签、并排按钮时，`inline-block` 很顺手，特别适合新手先把页面排起来。

---

## 2. 让按钮、标签、图片更容易排版，怎么做？

### 2.1 按钮：先把“样子”做像按钮

很多按钮其实就是 `a` 或 `button`。  
想让它像按钮，常见做法是：

- `display: inline-block`
- 加 `padding`
- 设背景色和文字颜色
- 去掉多余边框
- 加圆角

这样它才不会像一段普通文字，而是像一个可点击区域。按钮想好用，关键不是只靠文字撑着，而是给足内边距，让点击更舒服。

### 2.2 标签：要小而整齐，不要撑爆版面

像“热门”“新品”“推荐”这种标签，适合用 `span` 配合 `inline-block`。  
再加一点内边距、背景色、圆角，就会有明显的“徽章感”。

如果直接当纯文字，太弱；如果加上 `inline-block`，马上就更像一个组件。

### 2.3 图片：别让它莫名其妙留缝

图片混排时常会在底部留一点空隙，这是因为它默认按行内元素参与排版。

**经验建议：**
- 图片排版不稳时，可以试 `display: block`
- 想和内容并排时，可配合 `inline-block`

老赵提醒：图片看着不齐，很多时候不是边距错了，而是它的默认排版方式在捣乱。

---

## 3. 简单的水平排列思路：居中、并排、换行

### 3.1 居中：先分清“谁在居中”

先问自己：  
**是文字居中，还是块居中？**

- **文字居中**：`text-align: center;`
- **块元素居中**：固定宽度 + `margin: 0 auto;`

老赵提醒：`margin: 0 auto;` 一般要元素有明确宽度，不然本来就撑满了容器，居中也看不出来。做卡片、内容区、表单框时，先定宽度，再谈居中，效果更稳。

### 3.2 并排：先把几块东西排到一行

新手阶段最稳的思路不是先学复杂布局，而是先把几个元素排到一行。  
比如顶部导航项、商品分类标签、小卡片，都可以先用 `inline-block` 顶上。

**步骤：**
1. 给每个小块设置 `display: inline-block`
2. 设好宽度或内容宽度
3. 补上 `margin` 或 `padding`
4. 看看有没有挤、有没有歪，再微调

很多时候页面“看起来乱”，不是结构错了，而是间距没配好。

### 3.3 换行：别强行一条线排到底

页面不是越横排越高级。该换行就换行：
- 商品卡片太多，装不下就自然换行
- 导航太长，应该考虑缩短文案或调整结构
- 列表内容较多时，竖排反而更清晰

新手常见误区是硬追求“一排排满”，结果页面一窄就炸。老赵的经验是：**先保证清晰，再追求美观。**

---

## 4. 一个更贴近新手的小例子：做一个简单导航和卡片区

### 4.1 导航栏：一排放链接，别让它们乱跳

导航最常见的做法是：外层容器管整体背景和高度，内部链接用 `inline-block` 排成一行。

你要关注三件事：
- 链接之间的间距
- 文字是否垂直居中
- 点击区域够不够大

如果导航项太挤，先加左右 `padding`，通常比乱改属性更有效。

### 4.2 卡片区：让图片、标题、按钮各站各的

卡片是新手很好的练手对象，通常包含：
- 图片
- 标题
- 描述
- 按钮

做法很简单：先把卡片当成一个块，再把里面的元素分层排好。  
如果要让几张卡片并排，先给卡片设成 `inline-block`，再控制宽度、外边距和对齐方式。这样你就会明显看到，页面从“一坨”变成了“有秩序的几块”。

### 4.3 一个常见错误场景：把行内元素当块来用

比如你写了一个链接按钮：

```css
a {
  width: 120px;
  height: 40px;
  background: #2b7cff;
}
```

结果你发现宽高没什么效果。原因很简单：`a` 默认是行内元素。  
修正方式也简单：

```css
a {
  display: inline-block;
  width: 120px;
  height: 40px;
  background: #2b7cff;
}
```

再比如你把 `span` 当成卡片标题外层，想让它独占一行，结果它老是跟别的文字挤在一起。那就该换成块级元素，或者直接把它改成 `display: block;`。

老赵的判断很实用：**先看这个元素到底是“文字的一部分”，还是“一个独立小块”。** 先定角色，再定 display，基本不容易错。

## 5. 基础居中方法的实操理解

### 5.1 水平居中两种最常见方式

**方式一：文字居中**
- 适合标题、按钮组、说明文字
- 用 `text-align: center`

**方式二：块居中**
- 适合卡片、内容区、表单框
- 用固定宽度 + `margin: 0 auto`

这两种别混。文字居中解决“字往哪站”，块居中解决“整个盒子往哪站”。

### 5.2 垂直居中先别急着死磕

入门阶段先把水平排版搞定就够了。垂直居中以后有更多办法，不用一开始把自己绕进去。老赵建议：**页面先整齐，再追求高级对齐。**

---

## 6. 新手常见坑点：别在这里反复踩坑

### 6.1 以为所有元素都能随便改尺寸

不是所有元素改了 `width`、`height` 都立刻生效，尤其是行内元素。  
所以你改完没效果，先别怀疑人生，先看看 `display`。

### 6.2 行内元素和块级元素混用出问题

把 `span`、`a` 当大盒子用，或者让 `div` 去承担小装饰任务，常会让结构变乱。解决办法很简单：**先看这个元素是做大块结构，还是做小范围内容。**

### 6.3 只盯着并排，忽略内容是否清楚

布局不是比谁排得更满，而是比谁更容易读。  
如果并排导致拥挤，那就换行；如果一行太长，那就拆开。

### 6.4 赵老师的经验式避坑建议

- 先用块级思维搭骨架，再考虑并排
- 小元素想排整齐，优先试 `inline-block`
- 看到宽高不生效，第一反应查 `display`
- 布局先服务阅读，再谈美观
- 不要一上来就学复杂布局，先把基础排版练熟

---

## 结尾小结：先让元素按预期排开

这一章你只要记住一句话：**`display` 决定元素怎么站队。**

- `block`：适合大块区域，独占一行
- `inline`：像文字一样排队，适合小范围内容
- `inline-block`：既能并排，又能控制宽高，特别适合按钮、标签、图片排版

再加上基础的居中、并排、换行、导航和卡片这些实用场景，你就已经有了最初级但很实用的页面排版能力。记住老赵的话：**先让元素按预期排开，再谈更好看。** 下一步，我们就可以把这些方法放进真实页面里，继续把一个简单页面做得更像样。

# 第8章 第8章 简单浮动与定位：先会看懂老项目里的基础写法

## 开篇引入：为什么你得认识 float 和 position

学到这里，新手最容易卡住的，往往不是字体和颜色，而是打开老项目一看，满屏 `float`、`position`，完全不知道它们在干啥。老赵先说实话：**这俩东西不是让你一上来拿来“炫技”的，而是让你能看懂、能简单改、知道边界。**

老页面里常见的图文混排、右上角角标、商品图上的“热卖”标签，很多都离不开浮动和定位。你现在不用把布局体系全吃透，但至少要能判断：**这段样式是在干什么，会把页面弄成什么样。**

这一章先解决两件事：

- 看懂老项目里的 `float` 和 `position`
- 会改一些常见小效果，比如图文混排、角标、小红点、提示标签

记住一句老赵的话：**先会看懂，再会小范围使用，别一上来就指望它们包打天下。**

---

## 一、float 是干什么的：先知道它怎么“飘”

### 1. float 的基本感觉

`float` 可以先理解成“让元素往左或往右靠，并让后面的内容绕过去”。

```css
img {
  float: left;
}
```

这表示图片向左浮动，文字就可能跑到它右边去排。

### 2. 它以前常用来做什么？

早期 CSS 里，很多两栏布局、图文混排、导航横排，都会用 `float`。也就是说，**float 曾经是布局工具**，后来 `flex`、`grid` 更好用了，它就更多用于老项目兼容和简单排版。

常见场景就是：

- 左图右文
- 多个小块横排
- 导航项一排摆开

### 3. 浮动后页面会发生什么？

图片加了 `float: left;` 之后，会被“提”到左边，后面的文字会尝试绕过去，页面就变成图文贴在一起的样子。

### 4. 新手怎么理解它？

记住一句话：

- **float 主要影响周围内容的流动方式**
- 它不只是“往左靠一下”，还会改变后面元素的排布

老赵建议：**看到 float，先想它是不是在做图文混排或横排，别第一反应就去乱调 margin。**

---

## 二、浮动后为什么要清理：别让页面尾巴乱掉

### 1. 浮动后常见现象

浮动后，布局可能出现这些问题：

- 后面的文字会围绕它
- 父元素高度可能塌掉
- 同级元素被挤乱

最常见的坑是：父盒子明明有内容，但高度不对，背景也没包住，下面的内容还贴上来了。

### 2. 为什么要清理浮动？

因为浮动元素有时会让父容器“看不见”自己的内容高度，页面就乱了。这个时候要**清理浮动**，让父元素重新包住子元素。

### 3. 最常见的清浮动方法

老项目里常见的是伪元素清理：

```css
.clearfix::after {
  content: "";
  display: block;
  clear: both;
}
```

```html
<div class="clearfix">
  <div class="left">左边</div>
  <div class="right">右边</div>
</div>
```

意思很简单：浮动内容放里面，外层盒子别装作没看见，记得把高度撑起来。

### 赵老师的经验式避坑建议

**别一看到页面乱了就乱加 `float`。**  
浮动不是修页面的万能药，很容易把后面的结构也带歪。先想清楚你要的是图文混排，还是整块布局。

---

## 三、position: relative、absolute 的基础理解：先搞懂它们的角色

### 1. relative 是什么感觉？

`position: relative` 可以理解成：**元素还在原来的位置上，但可以做一点微调。**

```css
.box {
  position: relative;
  top: 10px;
  left: 20px;
}
```

它不会彻底跑走，更重要的是，它常常会给绝对定位的子元素提供参照。

### 2. absolute 是什么感觉？

`position: absolute` 更像是：**元素脱离正常排版，去找一个参照物，然后按这个参照物定位。**

这个参照物通常是最近的、设置了定位的父元素。你看到标签贴在图片右上角，或者小红点挂在按钮边上，很多时候都用了 `absolute`。

### 3. 定位四件套：top、right、bottom、left

这几个属性就是调位置的常用旋钮：

- `top`：离上边多远
- `right`：离右边多远
- `bottom`：离下边多远
- `left`：离左边多远

比如角标贴右上角：

```css
.badge {
  position: absolute;
  top: 8px;
  right: 8px;
}
```

### 4. 两个最常见的配合方式

老项目里最常见的是：

- 父元素：`position: relative;`
- 子元素：`position: absolute;`

这样子元素就能相对父元素边角去摆放，比如右上角角标、图片上的提示、小徽标。

---

## 四、定位在角标、小徽标、提示框里的简单应用

### 1. 角标怎么做？

比如卡片右上角有个“NEW”标签，常见做法就是：

```css
.card {
  position: relative;
}

.badge {
  position: absolute;
  top: 8px;
  right: 8px;
}
```

父元素负责当参照物，标签负责贴边。

### 2. 小徽标怎么做？

导航消息数、小红点、按钮角上的提示，通常也是这个思路。它们尺寸小、要求准，定位最顺手。

### 3. 提示框的简单小案例

```html
<div class="tip-box">
  <button>提交</button>
  <span class="tip">请先填写内容</span>
</div>
```

```css
.tip-box {
  position: relative;
  display: inline-block;
}

.tip {
  position: absolute;
  top: -28px;
  left: 0;
  background: #333;
  color: #fff;
  font-size: 12px;
  padding: 4px 8px;
  border-radius: 4px;
}
```

这个例子不复杂，但很实用。定位最常干的事，就是把一个小东西放到某个元素旁边、上面、角落里。

### 4. 最稳的操作流程

1. 找到父盒子  
2. 给父盒子加 `position: relative;`  
3. 找到要叠上去的小元素  
4. 给小元素加 `position: absolute;`  
5. 用 `top/right/bottom/left` 微调位置

### 5. 常见误区

- 子元素 `absolute` 了，父元素却没设 `relative`
- 角标位置对了，但换个内容就乱了
- 以为定位能解决所有排版问题

老赵提醒你：**定位适合做点状装饰和叠放效果，不适合硬拼整页主结构。**

---

## 五、float、relative、absolute 的对比：先知道各自解决什么问题

### 1. 它们分别适合什么场景？

- `float`：图文混排、老式横排
- `relative`：微调位置、当绝对定位参照
- `absolute`：角标、提示、小红点、叠放元素

### 2. 会不会影响文档流？

- `float`：会影响周围内容排布，常引出清浮动问题
- `relative`：元素还保留原位感，只是视觉上偏移
- `absolute`：通常脱离正常文档流，按参照物重新摆放

### 3. 选错工具会怎样？

想做角标却硬用 `float`，会很别扭；  
想挂红点却只会调 `margin`，会很难对齐；  
想做整页布局却到处用定位，后面维护会很痛苦。

**工具不是越多越好，关键是对症。**

## 六、新手常见坑点提醒：老赵带你少走弯路

### 1. 父元素没设 relative，absolute 找错参照

这是最经典的坑。你以为小标签会贴在卡片上，结果它跑到别的地方去了。原因通常就是：参照物没设对。

**排查顺序：先看父子关系，再看定位属性。**

### 2. 乱调 top/left，越调越偏

定位不是瞎碰运气。一个元素怎么都摆不对，先别猛加数值，先确认：

- 父元素是不是定位参照正确
- 元素本身宽高是否正常
- 这里到底该不该用 `absolute`

### 3. 浮动后父盒子塌陷

如果外层背景没包住内容，或者下面内容顶上来了，多半是浮动没处理好。记住：**浮动不只有“摆过去”，还有“收尾”。**

### 4. 新手常犯的排查步骤

老赵建议按这个顺序看：

1. 先看 HTML 结构，确认谁是父谁是子  
2. 再看有没有 `float` 或 `position`  
3. 再看父元素是否需要清浮动或设定位参照  
4. 最后再微调 `top/right/bottom/left`

做一个商品卡片，图片右上角有“热卖”标签。

这个案例很常见，很多“新品”“热卖”“推荐”标签都是这么做的。

# 第9章 第9章 新手常见坑点与赵老师避坑清单：样式没生效、间距乱、布局歪

## 开篇引入：样式写了，页面却没变？

新手学 CSS，最常见的崩溃现场就是：**样式没生效、间距忽大忽小、布局怎么调都歪**。先别急着怪浏览器，也别一上来推倒重来。赵老师带新人做项目，第一原则就一句：**先查最基础的地方，再查复杂的地方**。很多问题，本质上是路径写错、选择器没选中，或者优先级打架。

调试 CSS 可以按“查案”来：先看文件有没有真正加载，再看有没有选中这个元素，最后才看是不是被别的规则盖住。顺着这个顺序查，最省时间，也最不容易把自己绕晕。

---

## 一、CSS 写了却没生效时，先查这四件事

### 1. 先看 CSS 有没有真正引入

你写了 `.box { color: red; }`，但 HTML 里根本没链接这个文件，那当然没效果。先检查：

- `link` 路径对不对
- `rel="stylesheet"` 有没有写
- 文件名有没有拼错
- CSS 有没有保存
- 浏览器是不是缓存了旧文件

很多新手不是不会写，而是“写了但没接上”。赵老师建议养成习惯：**改完先确认页面真的加载了这个 CSS 文件**。

### 2. 再看选择器有没有选中元素

比如你写的是：

```css
.card { color: red; }
```

但 HTML 里用的是 `<div class="cards">`，那就选不中。**选择器、类名与 ID 要对上，大小写、单复数都要仔细看。**

### 3. 再看是不是被别的样式覆盖了

如果你写了 `color: blue;`，页面还是黑色，往往不是没写，而是被别的规则盖住了。这就要看**继承与层叠、优先级**。同一个元素被多条规则命中时，更具体、优先级更高的那条会生效。

### 4. 再看拼写和单位有没有写对

最常见的低级坑：

- 属性名写错，比如 `font-szie`
- 少了单位，比如 `width: 200`
- 少了分号，后面的样式跟着失效
- 颜色值、类名、ID 名拼错

### 赵老师经验式建议

遇到冲突别急着疯狂加选择器，先做两件事：

1. 看开发者工具里哪条样式被划掉了  
2. 想清楚“我到底想改谁”，再决定是用类名还是 ID

**新手阶段，简单、清楚、可控，比花哨更重要。**

---

## 二、选择器优先级冲突，按什么顺序排查？

当多个规则同时改同一个元素时，浏览器会按优先级决定谁生效。先记住一个实用结论：

- **ID 通常比类名强**
- **类名通常比标签选择器强**
- **越具体的选择器，越容易赢**

所以做页面样式时，尽量优先用类名控制一个局部区域，比如：

```css
.tip { color: red; }
```

比起直接改所有 `p` 标签，这样更安全，也更好维护。

### 排查顺序可以这么记

1. 先看元素有没有命中你写的选择器  
2. 再看是不是别的规则覆盖了它  
3. 再看是不是选择器太弱，压不过后面的样式  
4. 最后再考虑要不要调整类名或 ID

### 赵老师经验式建议

如果你发现“怎么改都不听话”，先问自己三句：

- 这个元素到底有没有命中选择器？
- 有没有别的规则在后面覆盖它？
- 我是不是该换更合适的类名，而不是继续堆更长的选择器？

**先把命中关系理顺，比硬拼优先级更靠谱。**

---

## 三、路径、缓存、拼写错误这些低级坑，怎么一眼识别？

这类问题最烦，但也最好查。

### 常见问题清单

- CSS 文件路径写错
- 文件没保存
- 浏览器缓存没刷新
- 选择器拼写错误
- 属性名写错，比如 `font-szie`
- 单位漏写，比如 `width: 200`
- 分号漏了，导致后面样式失效

### 实战提醒

如果你明明改了代码，页面却像“记住旧样式”，先试试：

- 强制刷新页面
- 看控制台有没有报错
- 用开发者工具确认样式是否加载
- 把问题缩到一个最小例子，再单独验证

赵老师的习惯是：**先把问题缩小到最小可验证范围**。别一口气改十处，改完你自己都不知道是哪一处起作用了。  
新手最怕“边修边加新 bug”，所以每次只改一个点，最稳。

---

## 四、margin、padding、line-height、width 最容易怎么用错？

### 1. margin 和 padding 搞混

- `margin`：元素外面的空隙
- `padding`：元素里面的空隙

页面“挤得慌”，很多时候不是内容太多，而是留白用错了。  
卡片和卡片之间离太近，通常先改 `margin`；卡片里的文字贴着边框，通常先改 `padding`。

### 2. line-height 不是字号

`line-height` 是**行高**，控制文字行与行之间的距离。写太小，段落挤；写太大，文本散。正文一般要比字号大一些，读起来才舒服。

### 3. width 不是越大越好

给盒子设宽度时，要注意内容、内边距和边框可能一起把整体撑大。页面突然横向溢出，先想是不是：

- `width` 太宽
- `padding` 加上后超出预期
- 没考虑盒模型

### 4. 一个很常见的误用案例

比如你想做一个按钮：

```css
.btn {
  width: 200px;
  padding: 20px;
  line-height: 20px;
}
```

结果按钮看起来又宽又怪。问题通常不是“按钮写错了”，而是 **width、padding、line-height 一起没算好**。这时候别急着继续加属性，先想：

- 我要的是按钮内容居中，还是按钮整体变大？
- padding 是不是已经够了？
- line-height 是不是和字体大小不匹配？

### 赵老师经验式建议

先别追求“精确像素”，先把关系理顺：**外面留空用 margin，里面留空用 padding，文字舒不舒服看 line-height，盒子会不会撑破看盒模型。**

---

## 五、页面太丑时，先别乱改，按什么顺序排查？

赵老师建议你按这个顺序来：

### 第一步：先保结构

先确认标题、图片、按钮、段落层级清楚，别先忙着改颜色。结构乱了，样式只会越补越乱。

### 第二步：再统一基础样式

先处理：

- 字体字号
- 行高
- 文本对齐
- 颜色
- 背景
- 边框
- 内外边距

这一步的目标不是炫，而是**干净、整齐、统一**。很多页面只要把这些基础样式理顺，立刻就能从“能看”变“顺眼”。

### 第三步：最后调布局

再看 `display`、简单浮动和定位这些基础布局方式。别一开始就上复杂布局，先把块级、行内、并排、居中这些常见需求处理好。

### 第四步：小范围验证

每次只改一个模块，比如先把卡片样式做对，再复制到其他卡片。**先小范围验证，再逐步扩展样式**，这是老赵带新人最推荐的方法。

---

## 六、再补两个新手常见小坑

### 1. 盒子看着“歪”，不一定是布局坏了

有时候不是元素真的歪，而是：

- 左右 `margin` 不一致
- 父元素有默认内边距
- 图片默认是行内元素，底下会多出空隙

这种情况先别怀疑大方向，先把基础间距清掉，再看页面是不是就顺了。

### 2. 浮动和定位别一上来就乱用

**简单浮动概念**和**简单定位概念**都能解决一些排版问题，但新手最容易用乱。  
如果一个小图标，本来靠 `display` 或 margin 就能摆好，就别急着上 `float` 或 `position`。能用简单办法解决，就先别把页面搞复杂。

---

## 小结：别怕报错，怕的是乱改

CSS 入门阶段，真正拉开差距的，不是会不会堆很多属性，而是**会不会排查问题**。记住这个顺序：**引入是否正确 → 选择器是否选中 → 优先级是否冲突 → 路径和拼写是否出错 → 间距和盒模型是否算对**。

以后你遇到“样式没生效、间距乱、布局歪”，不要慌，按这个清单一步步查。赵老师的经验就一句：**先定位问题，再动手修，别让页面丑得更乱。**  
新手只要把这套排查顺序养成习惯，后面做个人主页、商品展示页，都会顺手很多。

# 第10章 第10章 页面美化的基本套路：从零把一个页面做整洁

做 CSS 入门，新手最容易犯的错，就是“哪里丑改哪里”。今天调字体，明天改颜色，后天又补间距，结果页面越改越乱。赵老师带新人做项目时，最怕的就是这个顺序反了。

正确思路只有一句：**先搭骨架，再做统一，再补细节。**  
先让页面看起来像一个整体，再去抠局部精致感。页面从“能用”变成“整洁”，靠的不是炫技，而是这套最基础的美化套路。

---

### 一、先统一字体、字号和基础行高

页面乱，很多时候不是内容问题，而是**文字没有统一规则**。新手做页面，第一步别急着加阴影、动画，先把全局文字定住。

#### 1. 先做全局基础设置

常见做法是直接给 `body` 统一字体、字号和行高：

```css
body {
  font-family: Arial, "Microsoft YaHei", sans-serif;
  font-size: 16px;
  line-height: 1.6;
}
```

这样做很实用：

- **字体统一**：不会一会儿宋体一会儿黑体，显得乱。
- **字号统一**：阅读节奏稳定。
- **行高统一**：文字更松，页面更舒服。

如果你做的是个人介绍页、商品详情页、简单博客页，这一步基本必做。

#### 2. 行高为什么关键

行高直接影响“好不好读”。文字挤在一起，用户看着累；太大又显得散。新手先记一个实用标准：**正文行高一般比字号略大，常用 1.5 到 1.8。**

```css
p {
  font-size: 16px;
  line-height: 1.7;
}
```

段落会立刻比默认样式舒服很多。

#### 3. 字体字号要有层次

页面不能所有字一个样，至少要分出：

- **标题**：更大、更醒目
- **正文**：适中，方便阅读
- **辅助说明**：略小、颜色浅一点

```css
h1 { font-size: 28px; }
h2 { font-size: 22px; }
small, .tip { font-size: 14px; color: #666; }
```

有了层次，读者一眼就知道重点在哪。

#### 4. 赵老师的经验式避坑建议

- 不要每个段落都重复写字体和字号，先统一到 `body`。
- 标题、正文、按钮可以再局部微调，但一定是**先统一，再局部**。
- 别一上来就用花哨字体，先用常见、安全、清晰的字体组合。
- 新手最常见的错，是字号乱跳，页面没有层级，看起来就脏。

---

### 二、先定主色、背景色、文字颜色，再做细节调整

页面美化第二步，不是“加颜色”，而是**定颜色体系**。新手常见问题是按钮一会儿蓝一会儿绿，卡片背景又灰又粉，整页没有主次。

#### 1. 先定三种基本颜色

先把这三类颜色想清楚：

- **主色**：强调重点，比如按钮、标题高亮
- **背景色**：决定页面整体气质
- **文字颜色**：保证阅读清楚

```css
body {
  background: #f7f8fa;
  color: #333;
}

.btn {
  background: #1677ff;
  color: #fff;
}
```

浅背景、深文字、主色按钮，这种搭配最稳，页面会干净很多。

#### 2. 颜色的判断标准

- **文字必须清楚**：深字配浅底，浅字配深底。
- **重点必须突出**：重要信息只用一种主色强调，别到处乱用。
- **背景别抢戏**：背景是衬托内容，不是和内容争存在感。

如果页面“花”，通常不是颜色少，而是颜色没有规则。哪怕只用一个主色、一个背景色、一个正文色，只要分工明确，页面也会很稳。

#### 3. 常见误区

- 背景太深，正文又用深色，导致看不清。
- 同一页面用了太多亮色，视觉焦点丢失。
- 链接、按钮、标签颜色没有规则，页面像拼贴。

赵老师建议你记住：**一个页面先控制住 1 个主色、1 个背景色、1 个正文色，就已经赢一半了。**

---

### 三、用盒模型拉开层次，用边框和圆角提升观感

页面从“挤成一团”变成“有层次”，核心靠盒模型。新手不用先背太多理论，只要记住：**内容、内边距、边框、外边距**，这四个东西决定元素怎么占地方、怎么分开。

#### 1. 内外边距解决什么问题

- **padding 内边距**：让内容别贴着边框，更舒服
- **margin 外边距**：让元素和元素之间拉开距离

```css
.card {
  padding: 16px;
  margin-bottom: 16px;
  border: 1px solid #e5e7eb;
  border-radius: 8px;
  background: #fff;
}
```

这样卡片会比“裸文字堆在一起”更像一个完整模块。很多新手页面像草稿，就是因为内容贴边、模块挤在一起，没有呼吸空间。

#### 2. 边框和圆角的作用

- **边框**：划分区域，增强结构感
- **圆角**：让页面更柔和，不那么硬

但边框不是越多越好。新手常见问题是每个模块都加粗边框，页面立刻像表格。赵老师的经验是：**边框要轻，圆角要适度，重点是分层，不是装甲化。**

#### 3. 盒模型的实用理解

你可以把一个元素看成一个盒子：

- 内容在中间
- `padding` 负责“里面舒服”
- `border` 负责“边界清楚”
- `margin` 负责“外面有距离”

如果按钮不好点、卡片显得挤，先检查这四层。很多排版问题，不是代码错，而是盒子没处理好。

---

### 四、通过对齐、间距、排版建立清晰结构

页面整洁与否，很大程度上取决于**对齐**和**间距**。很多新手页面看着乱，不是内容错，而是“没对齐”和“没节奏”。

#### 1. 文本对齐先统一

常见做法：

- 标题左对齐：适合大多数内容页
- 按钮文字居中：更稳
- 图片和卡片模块尽量按同一边缘排列

```css
h1, h2 {
  text-align: left;
}

.btn {
  text-align: center;
}
```

对齐这个动作很朴素，但效果很明显。标题、正文、按钮的边缘对齐得好，页面会立刻专业一点。

#### 2. 间距要有规律

别每个地方都随手写一个 13px、17px、23px。  
更适合新手的是固定一套间距节奏：

- 模块之间：24px 或 32px
- 标题和正文：12px 或 16px
- 段落之间：8px 或 12px

这样页面会更统一，不会东一块西一块。你可以把间距理解为页面节拍，节拍稳了，页面就稳了。

#### 3. `display` 的基础用法

`display` 决定元素怎么排：

- `block`：独占一行，适合标题、段落、容器
- `inline`：跟文字混排，适合小标签
- `inline-block`：能排成一行，也能设尺寸，适合按钮、标签

```css
.tag {
  display: inline-block;
}
```

如果元素总是挤不开或排不整齐，先看看是不是 `display` 没选对。按钮、标签这类小块内容，通常用 `inline-block` 更方便控制。

---

### 五、页面美化的顺序建议：先大后小、先整体后局部

赵老师最想提醒你的，就是这一步。**页面美化不是修补匠思路，而是搭架子思路。**

#### 1. 正确顺序

建议按这个顺序来：

1. 统一全局字体、字号、行高
2. 定背景、文字主色
3. 处理主要模块的盒模型
4. 统一对齐和间距
5. 最后微调按钮、标题、标签等细节

这个顺序的核心，是先保证页面整体不乱，再让局部变精致。这样改起来也省力，不容易返工。

#### 2. 为什么不能先抠细节

因为局部越改越多，容易把整体节奏弄乱。比如你先把按钮调得很漂亮，后来又改页面宽度、卡片边距、字体大小，按钮又会不协调。

所以记住：**先整体，后局部；先大结构，后小装饰。**

#### 3. 新手检查清单

做完一个页面，先问自己：

- 字体是不是统一？
- 颜色是不是太多？
- 内容有没有拉开层次？
- 元素之间有没有合理间距？
- 标题、正文、按钮有没有对齐？
- 页面有没有一个明确重点？

如果这几条都过了，页面通常不会差。

---

### 六、简单浮动与定位：只拿来解决基础排版问题

这一章不展开复杂布局，只讲新手能用的部分。

#### 1. 简单浮动概念

`float` 以前常用来做图文排版，比如图片放左边，文字在右边。新手先知道它能实现“内容并排”的效果就够了。  
但要注意，浮动会影响普通文档流，后面可能要处理塌陷问题。

所以赵老师建议：**新手能不用浮动做主布局，就先别用。** 它更适合简单图文场景，不适合硬拼整个页面。

#### 2. 简单定位概念

`position` 可以把元素放到更明确的位置，比如：

- `relative`：相对自己原来的位置微调
- `absolute`：相对某个参考容器定位

新手阶段只要记住：**定位是拿来修补特殊位置的，不是拿来做整个页面主布局的。**  
如果什么都靠定位摆，后期很难维护。更稳的做法是先把普通排版和盒模型做好，定位只留给角标、提示、关闭按钮这些小地方。

---

### 七、一个更贴近实战的小例子：先整体，后局部

假设你现在要改一个简单的商品展示页，别一上来就调每个按钮的颜色。先按这个顺序走：

1. `body` 先统一字体、字号、行高
2. 页面背景改成浅灰或浅蓝，正文用深灰
3. 商品卡片加白底、圆角、轻边框和内边距
4. 标题左对齐，价格突出，说明文字放小一点
5. 最后再把购买按钮改成主色并居中

你会发现，页面一下子就从“零散”变成“成块”。这就是基础美化的价值：不是把页面变复杂，而是把信息排得更清楚。

---

## 本章小结

页面美化的基本套路，赵老师建议你记住四个词：**统一、分层、对齐、收口**。

- **统一**：先统一字体、字号、行高、基础颜色
- **分层**：用盒模型、边框、圆角把模块分开
- **对齐**：通过文本对齐和布局建立秩序
- **收口**：最后再做按钮、标签、细节微调

新手最常见的坑，就是一开始就抠细节，结果全局越来越乱。  
正确做法永远是：**先大后小，先整体后局部。**

如果你手里已经有一个简单页面，别急着“美化到很炫”，先按本章的方法，把它做得干净、整齐、舒服。做到这一步，你就已经从“会写 HTML”向“能做基础页面样式”迈出了一大步。

下一章我们就不只停在套路上了，直接拿一个小页面动手改，看看这些方法怎么真正落到实战里。

# 第11章 第11章 实战一：做一个简洁个人主页样式

## 开篇引入：个人主页，是新手最适合练手的页面

前面把 CSS 的基本玩法学了一遍，这一章直接上手做一个**简洁个人主页**。它最适合练习前面那些最常用的能力：**字体、字号、行高、颜色、背景、边框、内外边距、盒模型、display**，再加一点基础布局意识，就能把一个“只有内容”的页面，做成一个“看起来像样”的页面。

老赵带新人的经验是：**别一上来就碰复杂网站，先把一个小页面做顺**。个人主页结构简单，但信息完整，最适合练“怎么让页面整洁、有层次、看着舒服”。

一个典型个人主页通常分成几块：

- **头像区**
- **名字区**
- **简介区**
- **技能区块**
- **按钮区**

页面好不好看，不是因为花样多，而是因为**结构清楚、间距舒服、重点明确**。这就是这一章要练的核心。

---

## 一、个人主页的页面结构拆分：先搭骨架，再做样式

做样式前，先别急着写一堆 CSS。先问自己：**这个页面最重要的信息是什么？**

在个人主页里，通常顺序是：

1. **头像**：视觉入口
2. **名字**：核心身份
3. **简介**：补充说明
4. **技能**：辅助展示
5. **按钮**：引导行动

### 1）结构上怎么理解

你可以把它想成一张卡片：

- 外层是居中的容器
- 里面放头像、标题、文字、按钮、技能标签
- 每一部分之间留出空隙，不要挤在一起

页面不是元素堆放场，而是要在一个容器里有秩序地排布。容器负责“框住内容”，内容负责“表达重点”。

### 2）新手常见误区

很多新手会把所有内容堆在一起，结果页面像一团字。问题通常不是内容太少，而是：

- 没有层级
- 没有留白
- 没有统一字体和颜色
- 没有区分标题、正文和按钮

赵老师的建议很简单：**先分区块，再调细节；先定结构，再谈美化**。只要把信息分成几块，页面就已经成功一半了。

---

## 二、标题区、介绍区、按钮区怎么设计才顺眼？

这一部分的目标是：**让用户一眼看出重点**。

### 1）标题区：让名字成为焦点

名字通常要比其他文字更醒目。常见做法是：

- 字号更大
- 字重更粗
- 上下间距更舒服
- 颜色比正文更深，但不要太死黑

名字大不是为了炫，而是为了让用户快速知道：这是谁的主页。

### 2）介绍区：文字别太硬

简介最怕两件事：

- 字太小，看不清
- 行太挤，读起来累

所以这里要注意：

- 合理设置**字体字号**
- 适当设置**行高**
- 文字颜色不要太黑，略柔和一点更舒服
- 通常**文本对齐**用左对齐更自然

行高尤其重要。新手常只改字号，不改行高，结果字虽然大了，还是挤。记住：**字号决定看多大，行高决定读不读得顺**。

### 3）按钮区：要像按钮，不要像普通文字

很多新手写出来的“按钮”，其实只是一个带颜色的字。真正像按钮，至少要有：

- 背景色
- 内边距
- 边框或圆角
- 统一的文字风格
- 明确的点击感

按钮区一般放“联系我”“看作品”“下载简历”这类动作入口。注意，按钮不是越多越好，首页保留一两个最重要的入口就够了。

### 4）常见坑点

- 按钮和正文用同样字号，层级不清
- 链接颜色太跳，和整体风格不统一
- 文案太多，标题区被挤压
- 按钮没有内边距，看着像一行字

赵老师的建议是：**按钮要少而精，先把背景、间距、边框做对，再谈效果**。

---

## 三、卡片化排版与留白处理：为什么页面一“空”就高级一点？

个人主页要想整洁，最容易上手的办法就是卡片化排版。所谓卡片化，就是把内容放进一个有边界、有背景、有内边距的容器里。

### 1）卡片化要解决什么问题

它主要解决三个问题：

- **内容散乱**：把信息收拢到一个区域
- **焦点不明确**：让用户知道该看哪里
- **页面显得太空**：通过背景、边框、留白增强层次

### 2）卡片的基本组成

一个基础卡片通常包含：

- 背景色：区分内容区和页面背景
- 边框：轻微勾边，帮助识别区域
- 内边距：让内容不贴边
- 外边距：让卡片和页面其他部分保持距离

这时候就能理解**盒模型**了。元素不只是文字本身，还包括内容区、内边距、边框、外边距。新手最容易踩的坑，就是给卡片设了宽度，结果一加 padding 和 border，整个盒子变大，把布局挤坏了。

### 3）留白怎么做

留白不是浪费空间，而是给内容呼吸的地方。最常见的错误是：

- 标题、简介、按钮之间距离太近
- 技能标签挤成一团
- 卡片和页面边缘贴太死

留白的经验规则很简单：

- 同一组内容之间间距小一点
- 不同组内容之间间距大一点
- 外层容器不要紧贴浏览器边缘

只要把间距调顺，页面马上就会从“能看”变成“顺眼”。

---

## 四、基础页面美化思路：先统一，再突出

这一章真正要你建立的，不是某一个单独属性，而是**基础页面美化思路**。做个人主页时，可以按这个顺序来：

### 1）先统一整体风格

先把全局的字体、背景、文字颜色定下来。比如：

- 页面背景用浅色
- 正文用深灰
- 标题用更深一点的颜色
- 按钮只用一个主色

统一风格的好处很直接：页面不会乱，用户看起来也不会累。

### 2）再做主次关系

个人主页的主次很明确：

- 最重要的是头像和名字
- 第二层是简介
- 第三层是技能和按钮

也就是说，**视觉焦点要先落在名字和头像上**。如果所有内容都一样大、一样亮，页面就没有重点。你可以简单理解成：**让最重要的内容先跳出来，其他内容安静一点。**

### 3）最后做细节修正

细节主要看这几个点：

- 行高够不够
- 按钮像不像按钮
- 技能标签是否整齐
- 卡片边缘是否舒服
- 内容之间是否有呼吸感

赵老师的经验是：**先把大关系弄对，再去修小细节**。别一开始就盯着阴影、圆角这些小修饰，真正决定观感的，往往还是布局和间距。

---

## 五、如何让页面更整洁、更有层次？

这个问题本质上是在问：**怎样让用户知道先看什么、后看什么？**

### 1）用颜色建立层次

颜色不是越多越好。个人主页建议控制在：

- 1 个主色
- 1 个辅助色
- 1 套中性色

常见做法是：

- 页面背景用浅色
- 卡片背景用白色
- 文字用深灰而不是纯黑
- 按钮用主色突出

这样页面会更清爽。颜色在这里不是装饰，而是“引导视线”的工具。

### 2）用字体和字号建立层次

层次感很大一部分来自字号：

- 名字最大
- 简介次之
- 技能标签和辅助说明再小一点

同时字体风格要统一，不要一会儿粗一会儿花。很多新手会把每一块都写得差不多大，结果页面像一张平铺直叙的说明书，没有重点。

### 3）用边框和背景区分区域

- 技能标签可以用浅背景
- 卡片可以用细边框
- 按钮可以用更强的背景色

这样用户不用读完全部内容，也能知道这些区域分别干什么。背景和边框的作用，不只是“好看”，更是帮你分区、帮你组织内容。

### 4）判断标准

一个整洁的个人主页，至少应满足：

- 第一眼能看到名字和头像
- 文字不挤
- 按钮像按钮
- 技能区块像列表，不像一串乱字
- 整体颜色统一，不刺眼

如果页面“什么都写了，但什么都不突出”，通常就是层次没做出来。回头检查字号、颜色、间距，问题多半就在这几项。

---

## 六、基础响应式意识：先别追求复杂，但要知道怎么不崩

这章不展开复杂响应式，但你至少要有一点意识：**页面不能只在电脑上看起来正常**。

### 1）新手最容易忽视的问题

- 宽屏上很好看，手机上一团乱
- 容器太宽，文字太散
- 图片固定尺寸过大，挤坏排版
- 按钮过宽或过窄，视觉不协调

### 2）最基础的应对思路

你现在只需要记住几条：

- 外层容器不要写得过于死板
- 图片设置合理宽度，别撑爆卡片
- 文字区不要占满过宽的横向空间
- 按钮和技能标签尽量允许换行
- 内容之间留足空隙，避免窄屏时挤成一团

### 3）赵老师的经验式建议

入门阶段先做到一句话：  
**页面在小屏幕上不一定完美，但至少不能乱。**

先保证结构还在、信息顺序没乱、按钮还能看清，这就已经比很多初学者强了。别一上来就追求复杂适配，先把基本排版做稳，后面再慢慢优化。

---

## 七、简单浮动概念与简单定位概念：知道它们能干什么就够了

这一章是实战，不要求你把布局技巧学透，但有两个概念要先认识一下。

### 1）简单浮动概念

浮动可以简单理解成：**让某个元素往左或往右靠，让后面的内容围着它排**。

在个人主页里，浮动可以让头像和文字更灵活地组合。不过新手阶段先记住一件事：  
**浮动容易让布局变乱，没处理好时，后面的内容可能会挤上来。**

所以入门阶段，除非你明确知道自己在干什么，不然先用更稳妥的块级排版和居中方式，别一上来就追求花式布局。

### 2）简单定位概念

定位可以理解成：**让元素脱离普通文档流，放到你想放的位置上**。比如按钮角标、头像小标识、卡片角上的提示，都可能用到定位。

但新手最容易犯的错是：

- 一上来就乱用定位
- 父子关系没弄明白
- 结果元素飞来飞去，页面彻底乱掉

赵老师的建议是：**定位先会看、会用一点点就够了，别急着拿它做整页布局**。做个人主页时，大部分地方还是靠正常排版、盒模型和间距控制更稳。

### 3）一个小实操思路

比如头像旁边放一个“在线”小点，或者卡片右上角放一个“推荐”标签，这种小装饰就适合用简单定位。你先知道它能解决“元素叠放、角标摆放”这类问题就行。

---

## 八、把这些东西串起来：一个个人主页到底怎么落地？

现在把前面的内容串一下，你会发现个人主页其实就是一个很清楚的流程：

1. **外层做卡片**
   - 设置背景、边框、圆角、内外边距
   - 让内容先有一个整洁的容器

2. **顶部放头像和名字**
   - 头像是识别点
   - 名字是主视觉
   - 两者之间留出合适距离

3. **中间放简介**
   - 用合适字号和行高
   - 控制文本长度
   - 让内容好读

4. **下面放技能标签**
   - 用小背景或边框做区分
   - 排成整齐一行或多行

5. **底部放按钮**
   - 背景色统一
   - 内边距足够
   - 看起来像真正的操作入口

如果写完发现页面还是不舒服，优先检查这四件事：

- 间距够不够
- 颜色统一不统一
- 主次分得清不清
- 元素是不是都挤在一起

很多时候，页面不高级，不是因为少写了很多属性，而是因为**该留白的地方没留白，该突出的时候没突出**。

---

## 九、新手常见坑点提醒：这三类问题最容易毁掉页面

### 1）内容堆在一起

这是最常见的问题。原因通常是：

- 没有外边距
- 段落间距太小
- 没有分区块

解决办法：  
先给每个模块留足空间，再去调细节。页面是否高级，很多时候就差这一步留白。

### 2）视觉焦点不明确

如果名字、头像、简介、按钮全一样大、一样粗、一样色，用户不知道看哪。

解决办法：  
让“名字”和“头像”先站出来，再用简介和按钮做补充。你要明确主次，不要让所有内容抢戏。

### 3）按钮和文字风格不统一

有些新手会把按钮做得像一段普通文字，或者按钮颜色和整页风格冲突。

解决办法：  
按钮要和整体配色统一，同时通过**背景、边框、内边距、文字颜色**把它做成真正的交互入口。记住，按钮不是“加了颜色的字”，而是“有明确点击感的组件”。

### 4）赵老师的避坑建议

- 先统一字体，再调颜色
- 先拉开间距，再谈细节
- 先让页面有层次，再考虑花哨效果
- 宁可少一点装饰，也别把页面做乱
- 每次改样式后都整体看一遍，别只盯着一个模块

---

## 结尾小结：你现在练到的是“整理页面”的能力

这章的核心，不是让你记住多少属性名，而是让你知道：**个人主页怎么从一个“有内容的页面”变成一个“有设计感的页面”**。

你可以把实战步骤记成四步：

1. **拆结构**：头像、名字、简介、技能、按钮  
2. **定层级**：谁最大、谁最醒目、谁做辅助  
3. **做卡片**：背景、边框、内外边距、留白  
4. **统一风格**：颜色、字体、按钮、间距保持一致  

最后给你一个检查清单：

- 名字是否够醒目？
- 头像是否清楚？
- 简介是否好读？
- 按钮是否像按钮？
- 技能区是否整齐？
- 整体是否留白合理？
- 手机上会不会明显乱掉？

把这些问题都过一遍，你的第一个个人主页样式就已经合格了。下一步，可以继续把这套思路迁移到商品展示页、博客首页、简单落地页上去。先别急着做复杂动画和高级适配，先把基础排版、层次和统一风格练稳，这才是新手最值钱的进步。

# 第12章 第12章 实战二：做一个商品展示页或宣传卡片页

## 开篇引入：为什么这类页面最适合练手？

前面你已经学了字体、颜色、边框、间距这些基础能力，现在正好拿来做一个**商品展示页**或者**宣传卡片页**。这类页面结构不复杂，但很适合练综合能力：要会拆结构、会控制对齐、会突出重点，还要让几张卡片放在一起时统一、整洁。

老赵一直觉得，新手学 CSS 最怕的不是“不会某个属性”，而是“单个属性都会，放一起就乱”。所以这章不追求花哨，就做一件事：**把一个能用的页面，打磨得更像样。**

你可以把它当成一次小型实战：页面不求炫，但要有基本设计感。只要你能把卡片做得规整、重点清楚、间距舒服，离独立做一个简洁的个人主页或商品展示页就不远了。

---

## 一、先拆结构：图片、标题、价格、卖点、按钮

先别急着写样式，第一步永远是拆结构。一个商品卡片通常可以拆成这几块：

- **图片**：第一眼吸引人
- **标题**：告诉用户这是什么
- **价格**：最需要突出
- **卖点**：补充说明
- **按钮**：引导下一步操作

### 一个常见的 HTML 结构思路

```html
<div class="product-card">
  <img src="phone.jpg" alt="商品图片">
  <h3>轻薄手机</h3>
  <p class="price">￥2999</p>
  <p class="desc">轻薄机身，高清屏幕，长续航。</p>
  <button>立即购买</button>
</div>
```

这里有几个点要记住：

1. **类名比 ID 更适合做卡片样式**  
   卡片通常不止一个，用 `.product-card`、`.price` 这种类名更方便复用。ID 适合页面里唯一的元素，不要重复用。

2. **结构要清楚**  
   图片、标题、价格、按钮各司其职，后面改样式才省事。别把内容全塞一个 `div` 里，再靠样式硬救。

3. **重点信息要先被看到**  
   价格和按钮通常是转化核心，样式上要比说明文字更醒目。

赵老师的经验建议：**先想用户先看什么，再决定结构和视觉层级。** 这比照着效果图乱抄更稳。

---

## 二、颜色、边框怎么配，才能把商品重点顶出来？

商品页最重要的不是“每个地方都好看”，而是**让重点信息更突出**。新手最常见的问题就是颜色乱用，页面最后像调色盘。

### 1. 价格要比描述更醒目

```css
.price {
  color: #e60012;
  font-size: 24px;
  font-weight: bold;
}
```

价格是核心信息，通常要用更醒目的颜色、更大的字号和加粗来强调。

### 2. 用边框建立卡片边界

```css
.product-card {
  border: 1px solid #eee;
}
```

边框的作用不只是装饰，更是**把卡片从背景里分离出来**。如果没有边框，多个卡片挤在一起，页面很容易糊成一片。想柔和一点，可以再加圆角：

```css
.product-card {
  border: 1px solid #e5e5e5;
  border-radius: 8px;
}
```

### 3. 按钮颜色要和价格区分开

```css
button {
  background: #1677ff;
  color: #fff;
}
```

按钮是操作入口，颜色通常要和正文区分开。一个常见坑是：**价格、标题、按钮都用高饱和颜色**，结果主次不分，用户不知道先看谁。

### 新手常见坑点提醒

- 颜色太多，页面显得乱
- 所有文字都加粗，重点反而不突出
- 边框太黑太硬，卡片看起来很笨重

老赵建议：**一个页面先控制在 1 个主强调色 + 1 个辅助色 + 灰阶文字**，基本就够用了。新手先学会克制，比学会“花”更重要。

---

## 三、间距和对齐，是卡片感的关键

一个卡片好不好看，很多时候不在于用了什么高级属性，而在于**间距是否舒服、对齐是否统一**。

### 1. 用内边距让内容不贴边

```css
.product-card {
  padding: 16px;
}
```

`padding` 的作用是让内容和边框保持距离。没有内边距，文字和图片会贴着边，看起来很挤，也显得廉价。

### 2. 用外边距控制卡片之间的距离

```css
.product-card {
  margin: 12px;
}
```

`margin` 是卡片和卡片之间的距离。做列表时，外边距很重要，不然多个卡片会连成一片。

### 3. 统一文字对齐方式

```css
.product-card {
  text-align: center;
}
```

宣传卡片、商品展示卡片里，常见做法是居中对齐，这样整体更整齐。  
如果内容更密集，也可以让标题左对齐、描述左对齐，但关键是：**整页风格要统一，不要一张左对齐、一张右对齐。**

### 4. 图片尺寸尽量统一

```css
.product-card img {
  width: 100%;
  display: block;
}
```

这里 `display: block;` 很关键，能去掉图片底部可能出现的小空隙。新手经常忽略这一点，结果图片下面莫名其妙留一条缝。

### 经验式避坑建议

- 别让卡片里每个元素都用不同间距
- 别一会儿居中，一会儿左对齐
- 别让图片尺寸不统一，否则列表会像“拼盘”

页面整洁感，很多时候就是这样一点点抠出来的。

---

## 四、列表式展示和单卡片展示，做法不一样

商品页常见两种形式：**单卡片展示** 和 **列表式展示**。它们的思路不一样。

### 1. 单卡片展示：重点是“展示完整”

适合宣传页、活动页、单个推荐商品。做法上更强调：

- 图片大一点
- 标题清楚
- 价格突出
- 按钮明显
- 卡片整体居中

比如可以给外层一个固定宽度，再居中：

```css
.product-card {
  width: 300px;
  margin: 0 auto;
}
```

`margin: 0 auto;` 是个很实用的小技巧，能把块级元素水平居中。

### 2. 列表式展示：重点是“排得整齐”

适合商品列表、推荐栏、首页模块。新手阶段可以先用最简单的方法：

- 每张卡片固定宽度
- 用 `display: inline-block;` 或普通块级布局
- 控制好间距

例如：

```css
.product-card {
  display: inline-block;
  width: 220px;
  vertical-align: top;
  margin: 12px;
}
```

这里不用一下子学复杂布局，先记住一个基本思想：  
**列表式展示最怕高低不齐和挤在一起。**

### 简单浮动概念

如果你在旧页面里看到 `float: left;`，它常用于让卡片横向排列。你现在先记住它的作用就行：

- 可以让多个块级元素横向排开
- 但要注意清除浮动，不然父容器可能塌陷

入门阶段，**知道浮动能做横排就够了**，先把卡片排整齐，再补复杂知识。

### display 的实用理解

`display` 你现在主要记三个：

- `block`：独占一行，适合卡片、段落
- `inline-block`：像行内元素一样排布，但可以设置宽高
- `none`：不显示

老赵建议你先把 `display` 当成“元素怎么排”的开关。很多页面看起来乱，不是样式少，而是 `display` 用错了。

## 五、一个小案例：把普通商品块改成像样卡片

为了让你更直观看到效果，咱们拿一个很普通的商品块来改。

### 原始状态：能用，但不太好看

```html
<div class="product-card">
  <img src="phone.jpg" alt="商品图片">
  <h3>轻薄手机</h3>
  <p class="price">￥2999</p>
  <p class="desc">轻薄机身，高清屏幕，长续航。</p>
  <button>立即购买</button>
</div>
```

如果不写样式，它只是内容堆在一起，谈不上“商品页”。

### 第一步：先让它像一个卡片

```css
.product-card {
  width: 280px;
  border: 1px solid #e5e5e5;
  border-radius: 8px;
  padding: 16px;
  margin: 16px;
}
```

这一步做完，卡片感就出来了：有边界、有空间，不再是硬邦邦一坨内容。

### 第二步：把重点信息拎出来

```css
.price {
  color: #e60012;
  font-size: 24px;
  font-weight: bold;
  margin: 8px 0;
}

.desc {
  color: #666;
  font-size: 14px;
  line-height: 1.6;
}
```

这一步是视觉层级：价格更醒目，说明文字更安静，页面就不会乱抢戏。

### 第三步：把按钮做成明确入口

```css
button {
  background: #1677ff;
  color: #fff;
  border: none;
  padding: 10px 16px;
  border-radius: 4px;
  cursor: pointer;
}
```

按钮不用复杂，但要有“我可以点”的感觉。颜色、圆角、内边距到位，按钮就比默认样式精神很多。

### 第四步：让图片和整体风格统一

```css
.product-card img {
  width: 100%;
  display: block;
  border-radius: 4px;
}
```

图片统一后，卡片整体会更稳。新手最容易忽略的就是图片尺寸，一乱，整个列表看着就散。

## 六、综合复盘：这次到底改进了什么？

这一步最重要。很多新手写完页面会觉得“我都写了呀，怎么还是不好看？”  
原因通常不是少写了属性，而是**没有做结构和视觉上的整理**。

### 这次改进了什么？

#### 1. 结构更清楚了

以前可能是图片一张、文本一堆、按钮随便放；现在变成图片、标题、价格、卖点、按钮。这样信息顺序更符合用户阅读习惯。

#### 2. 重点更突出

- 价格更醒目
- 按钮更有行动感
- 描述文字更低调

这就是视觉层级。别把所有元素都做成同一种强度，不然页面就像一张没有重点的说明书。

#### 3. 间距更舒服了

- `padding` 让内容不贴边
- `margin` 让卡片之间有距离
- 统一的对齐方式让页面更整洁

#### 4. 卡片像一个整体了

- 边框把内容框住
- 圆角让视觉更柔和
- 统一宽度让列表更稳定

### 检查清单：做完卡片后先看这 5 点

- 标题和价格谁更重要？能不能一眼看出来？
- 卡片内部是否太挤？
- 多张卡片摆在一起是否整齐？
- 按钮颜色是否抢过了价格？
- 图片尺寸是否统一？

只要这几项过关，页面通常就不会太差。新手不要一上来就追求“高级感”，先把“整洁感”做好，往往已经超过很多人了。

---

## 结尾小结：下一步怎么继续练

到这里，你已经可以独立做一个基础的商品展示页或者宣传卡片页了。你这次真正练到的，不只是几个属性，而是三件事：

1. **先拆结构，再做样式**  
   先分清图片、标题、价格、按钮各自干什么，再开始写 CSS。

2. **用颜色、边框和间距做主次**  
   商品页最怕平均用力，价格和按钮要更突出，说明文字要退后一点。

3. **用 display、对齐和统一尺寸把页面收住**  
   卡片能不能像一个系列，关键就在这里。

赵老师最后再提醒一句：**新手学 CSS，不怕慢，就怕乱。** 每次只解决一个问题：这次先把卡片做整齐，下次再把列表排好。只要一步一步练，页面一定会从“能用”变成“像样”。

如果你想继续往下学，建议先把前面讲过的选择器、盒模型和 `display` 再练熟一点，再去做个人主页、商品列表或简单活动页。别急着上复杂效果，先把基础样式做扎实，后面会顺很多。
